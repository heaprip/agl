# Казус: термины родства как разложение по сгруппированным осям

**Черновик. Не принято.** Проверка H42 (разложение понятий) и H44 (точные
векторы по сгруппированным осям). Прототип вне ядра:
`cargo run --release --example kinship` (`examples/kinship.rs`). Правильные
ответы на вопросы известны заранее любому носителю языка, поэтому итог можно
проверить, не разбираясь в устройстве.

## Уровни

**Уровень 0 — точный путь** от «я» к родственнику по трём простым шагам:
родитель `P`, ребёнок `C`, супруг `S`. У каждого шага есть пол того, к кому он
ведёт: `m`, `f` или `x` (любой). `P`, за которым сразу идёт `C`, — брат или
сестра, другой ребёнок того же родителя.

| Термин | Разложение | Читается |
| --- | --- | --- |
| мать | `Pf` | родитель-женщина |
| брат | `Px Cm` | сын родителя |
| дядя | `Px Px Cm + Px Px Cf Sm` | брат родителя **или** муж сестры родителя |
| тесть | `Sf Pm` | отец жены |
| avunculus (лат.) | `Pf Px Cm` | брат матери |

Термин — объединение путей: у «дяди» два смысла, кровный и через брак.

**Уровень 1 — сгруппированные оси.** Путь сворачивается в форму:

- поколение: число `P` минус число `C`;
- степень: число рождений, `P` плюс `C`;
- свойство: есть ли в пути брак;
- прямая линия: только вверх или только вниз, без брака;
- линия: по матери или по отцу, если путь начинается с родителя;
- пол родственника.

**Уровень 2 — классы над формой:** кровный родственник, свойственник, предок,
потомок.

Пол конечен, поэтому каждый шаблон раскрывается в конечное множество точных
путей. Подчинение на любом уровне — вложение этих множеств, без приближений.

## Что значит «разложение работает корректно при переходе уровней»

Три закона, которые прототип проверяет на всех терминах:

1. **Переход вверх сохраняет подчинение.** Если «мать» — частный случай
   «родителя» на уровне 0, то и на уровне 1. Из 74 таких пар сохранились все.
   Закон выполняется по построению: уровень 1 — образ уровня 0.
2. **Два пути к одному классу дают одно и то же.** «Свойственник» определён
   дважды: через форму уровня 1 и прямо на путях («есть шаг `S`»). Совпадает в
   536 проверках. Это настоящая перекрёстная проверка: определения написаны
   независимо.
3. **Состав путей складывает поколение и степень**, как умножение чисел
   складывает показатели при простых: в 17 956 парах ни одного исключения.
   Прямая линия так не складывается: «родитель · ребёнок» — уже брат, а не
   прямая линия (320 пар).

**Вниз равенство не переносится.** На уровне 1 равны, на уровне 0 различны:

- тесть и свёкор, тёща и свекровь, деверь и шурин;
- father-in-law с тестем и со свёкром.

Это не ошибка, а то, что уровень выбрасывает: чей супруг. Ровно так глюкоза и
фруктоза равны по элементам и различны по группам атомов (H44).

## Вопросы

Все 27 ответов совпали с ожидаемыми. Самые показательные:

| Вопрос | Ответ | Почему это интересно |
| --- | --- | --- |
| дядя — кровный родственник? | нет | один смысл «дяди» — через брак |
| у дяди есть кровный смысл? | да | термин смешанный, это видно |
| брат матери = мать брата? | нет | порядок шагов — структура, не мешок |
| мать брата = мать? | да, по умолчанию | свёртка `P C P → P`: у брата те же родители, кроме сводных |
| тесть = свёкор? | на уровне 0 нет, на уровне 1 да | |
| father-in-law = тесть ∪ свёкор? | да, на обоих уровнях | английский термин — объединение двух русских |
| patruus ∪ avunculus = кровный дядя? | да | латынь различает линию, русский нет |
| общее у дяди и тёти | `Px Px Cx + Px Px Cx Sx` | «брат или сестра родителя либо их супруг» — НОД |

**Языки выбирают разные уровни.** Русский различает тестя и свёкра (уровень 0),
английский — нет (father-in-law, уровень 1). Латынь различает дядю по матери и
по отцу, русский и английский — нет. Узлы разных языков связываются точным
отношением: равенство, вложение, объединение (к H3).

## У теста есть зубы

Поломки по одной:

| Поломка | Что поймало |
| --- | --- |
| прямая линия, не исключающая брак | закон 2: отчим попал в предки |
| дядя без смысла «муж тёти» | 3 вопроса, включая `uncle = дядя` |
| пол родственника берётся от «я» | вопрос «тесть = свёкор на уровне 1» |
| тесть без условия «я — мужчина» | ничего |

Последняя поломка ничего не сломала, и это находка. Условие «я — мужчина» в
определении тестя было лишним: тесть — отец жены, пол спрашивающего определению
не нужен. Сначала помощник записал тестя как `m| Sf Pm`, и прототип ответил, что
father-in-law шире пары «тесть, свёкор» — из-за однополых браков. Это был
артефакт лишнего условия. После исправления father-in-law = тесть ∪ свёкор на
обоих уровнях.

## Вверх по плоскостям

Цепочка автора: родитель, ребёнок → человек → биологическая классификация →
существо (углеродная жизнь) → живое. И так в каждой плоскости.

На деле от «родителя» вверх ведут две разные цепочки:

- **что это за отношение:** родитель → предок → кровное родство;
- **кто занимает роль:** родитель — человек → Homo sapiens → … → живое. Это сорт
  роли: «то, что может занимать роль родителя» (H18).

В разных плоскостях обе цепочки свои:

| Плоскость | Отношение «родитель» | Кто занимает роль |
| --- | --- | --- |
| биологическая | происхождение: передача генов, размножение — свойство живого | организм, не обязательно человек: родители есть у кошки |
| общественно-правовая | права и обязанности родителя, семья, общественное отношение | физическое лицо, субъект права |
| логическая | бинарное отношение: иррефлексивное, асимметричное; предок — его транзитивное замыкание | сущность |

Шаг «родитель → человек» принадлежит плоскости человеческого родства. В
биологической плоскости «родитель» шире человека.

**Плоскости расходятся уже внизу.** При усыновлении законный родитель не
биологический. При суррогатном материнстве «матерей» три: генетическая,
вынашивающая, законная. Здесь казус должен дать локализованное противоречие
между плоскостями — в прототипе этого пока нет.

## Чего нет в прототипе

- Цепочки вверх — только таблица выше, не вычисляются.
- Плоскостей нет: одно разложение на все случаи.
- Группа осей не становится осью следующего уровня сама. Уровень 1 —
  фиксированный набор, написанный руками. Сгруппировать `P C` в ось «брат,
  сестра» прототип не умеет.
- Сводных братьев не выразить: «общий ровно один родитель» — это счёт, а не
  путь.
- `C P` («родитель моего ребёнка») — это я или мой супруг. Свёртки для этого
  нет, и такие пути считаются родственниками второй степени.
- Родство — цепочка, а понятие вообще — граф. Для родства пути хватает, для
  «убийства» из «Праведных» — нет.
