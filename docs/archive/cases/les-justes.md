# Казус: «Праведные» (Камю, 1949) — первый моральный казус

**Черновик. Не принято.** Первая проверка метаядра v0 на весах морали, ради
которой оно и строится (решение 7). Текст пьесы защищён авторским правом,
поэтому здесь только пересказ, без цитат.

## Метаядро v0 на входе

| # | Примитив |
| --- | --- |
| 1 | отношение (у каждого экземпляра есть id) |
| 2 | отрицание |
| 3 | тождество в плоскости |
| 4 | плоскость со структурой: вложение, RCC, наследование, допуск |
| 5 | `holds(claim, plane, status)` |
| 6 | основание: строгое или отменяемое, с опровергателем |
| 7 | типизированный пробел |

Встроенные: числа, размерности, агрегация.

## Фабула

Москва, февраль 1905 года. Боевая группа эсеров готовит убийство великого
князя.

- **Каляев** должен бросить бомбу в карету. Бомбу он не бросает: в карете,
  кроме князя, его малолетние племянник и племянница.
- Вечером группа спорит. **Степан** — бывший каторжник — считает, что бросить
  было надо: счастье будущих поколений важнее двух детей. **Дора** и
  **Анненков**, руководитель группы, на стороне Каляева: у разрушения тоже
  есть границы.
- Через два дня Каляев бросает бомбу. Князь в карете один и погибает.
- В тюрьме Каляеву предлагают помилование в обмен на выдачу товарищей. Вдова
  князя просит его покаяться. Он отказывается от того и другого: убийство
  оправдано только тем, что убийца платит за него собственной жизнью.
- Каляева казнят. Дора просит, чтобы следующую бомбу дали ей.

У пьесы есть историческая основа: Иван Каляев, покушение 1905 года,
«Воспоминания террориста» Савинкова. Свою позицию по этим людям Камю
развернул в главе «Les meurtriers délicats» («Щепетильные убийцы») из
«Бунтующего человека» (1951).

## 1. Плоскости

```
P_hist     — события 1905 года
P_play     — мир пьесы
models(model: P_play, target: P_hist, plane: P_literature)   # пьеса моделирует историю
src: memoir(author: savinkov, about: P_hist)
holds(claim: aborted_attempt_1905, plane: P_hist, status: testimony)  # свидетельство участника
```

Мораль — ось плоскости «чья точка зрения», ветки — по носителям весов:

```
branch: kaliayev, stepan, dora, annenkov, voinov    # персонажи пьесы
branch: camus                                       # авторская позиция, из эссе
```

## 2. Факты: одинаковы для всех веток

```
f1: plan(group: combat_org, act: kill, target: grand_duke)
f2: in_carriage(carriage: c1, person: grand_duke, attempt: a1)
f3: in_carriage(carriage: c1, person: nephew, attempt: a1)
f4: in_carriage(carriage: c1, person: niece,  attempt: a1)
f5: child(person: nephew)   f6: child(person: niece)
f7: ¬threw(agent: kaliayev, attempt: a1)
f8: threw(agent: kaliayev, attempt: a2)
f9: in_carriage(carriage: c2, person: grand_duke, attempt: a2)   # больше никого
f10: offered(by: police, to: kaliayev, deal: pardon_for_names)
f11: ¬accepted(agent: kaliayev, deal: pardon_for_names)
holds(claim: f1…f11, plane: P_play, status: text)
```

Спор между ветками не о фактах. Это первая проверка: факты стоят один раз, в
`P_play`, и ни одна ветка их не переписывает.

## 3. Веса веток

### Степан: компромисс, без границы

```
s1: dominates(over: lives(?victims), by: liberation(future_generations))
s2: ought(throw(?a)) ⇐ plan(target: ?t), in_carriage(?c, ?t, ?a), s1
holds(claim: s1, s2, plane: P_moral, status: weight, branch: stepan)
```

Числа не нужны. Степан не считает «двое детей против миллионов» — он
утверждает **превосходство**. Вес — это отношение частичного порядка, а не
число.

### Каляев: граница

```
k1: strict ¬ought(kill(?x)) ⇐ child(?x)                          # граница, строгое основание
k2: ought(kill(?t)) ⇐ oppressor(?t), plan(target: ?t)             # отменяемое
k3: defeats(k1, k2)                                               # строгое бьёт отменяемое
holds(claim: k1…k3, plane: P_moral, status: weight, branch: kaliayev)
```

**Нагрузка J1.** Лексический приоритет («детей нельзя ни за какую цену»)
выразился **без нового примитива**: граница — строгое основание, компромисс —
отменяемое. Пункт 6 метаядра, разделение строгого и отменяемого, несёт мораль
так же, как в биологии нёс «закон против эмпирического правила».

### Дора и Анненков

Дора — ветка Каляева, к которой добавлено правило «у разрушения тоже есть
порядок». Это та же граница, и выводит она то же самое. Анненков добавляет
процедуру: решение принимает группа, голосованием. Это не вес, а
институциональная норма:

```
a1: decides(body: combat_org, by: vote)
holds(claim: a1, plane: P_play, status: text)
```

### Воинов: «не могу» — это не «не должен»

Воинов признаётся, что больше не может бросать бомбы, и просит перевести его
в пропаганду.

```
v1: ¬can(agent: voinov, act: throw)          # описательное: страх
holds(claim: v1, plane: P_play, status: text)
```

**Нагрузка J2.** Это описательное утверждение, не норма. Линтер «есть →
должно» обязан не принимать `¬can` за `¬ought`. Та же граница, что между
биологической функцией и моралью в казусе с газообменом (Z4).

## 4. Воспроизведение: критерий H14b

| Покушение | Факты | Ветка Степана | Ветка Каляева | В тексте |
| --- | --- | --- | --- | --- |
| a1, с детьми | f2–f6 | `ought(throw)` ✓ | граница k1 → `¬ought(throw)` ✓ | не бросил ✓ |
| a2, князь один | f9 | `ought(throw)` ✓ | k1 не срабатывает, k2 → `ought(throw)` ✓ | бросил ✓ |

Ветки расходятся **только** в a1, и только в пункте «можно ли убивать детей».
В a2 они согласны. **Конфликт локализован ровно на столкновении ценностей**
(критерий H14c) — это выведено, а не объявлено.

**Проверка разрыва «есть → должно»:**

```
bad: ¬ought(throw) ⇐ in_carriage(c1, nephew, a1)
```

Отклонено: нормативный вывод из одного описательного факта. Нормативная
посылка (k1) появляется только в ветке.

## 5. Отложенная сцена: тюрьма

Отказ от помилования (f11) намеренно не использовался при подборе весов. Это
отложенный тест, как предлагал рецензент.

**Попытка 1 — веса только из второго действия (k1–k3).** Отказ от помилования
из них **не выводится**. В k1–k3 нет ничего о собственной жизни: веса,
подобранные по одной сцене, объясняют её и не больше. **Тест провален**, и это
ровно тот риск переобучения, который рецензент назвал вторым.

**Попытка 2 — веса из авторской теории.** В «Щепетильных убийцах» Камю
формулирует принцип людей 1905 года: убийство допустимо только тогда, когда
убийца отдаёт за него свою жизнь. Одна жизнь за одну жизнь. Это граница с
двух сторон:

```
c1: strict ¬ought(kill(?x)) ⇐ innocent(?x)
c2: strict justified(kill(?t), by: ?a) ⇒ ought(pay_with_life(?a))     # мера: жизнь за жизнь
c3: ought(kill(?t)) ⇐ oppressor(?t)                                    # отменяемое
holds(claim: c1…c3, plane: P_moral, status: weight, branch: camus, source: rebel_essay)
```

Из c2 следует: принять помилование значит остаться убийцей без оплаты, то есть
нарушить меру. Значит, `¬accept(pardon)`. **Сцена в тюрьме выводится ✓.** На
тех же весах и a1 (`innocent ⊇ child`), и a2 тоже выводятся ✓.

**Вывод о методе.** Веса нельзя снимать со сцены, которую ими же потом
объясняют. Их надо брать из **авторской теории** и проверять на тексте. Для
Камю теория есть — «Бунтующий человек». Для веток персонажей (Степан) её нет,
и они остаются подобранными по тексту, со всеми рисками.

## 6. «Невинный» — пробел нового типа

Каляев говорит «дети», Камю — «невинные», и их надо связать.

```
c1 использует innocent(?x); k1 использует child(?x)
holds(claim: subsumes(innocent, child), plane: P_moral, branch: camus)   # дети — невинные
```

Но что такое «невинный», ствол не скажет. Виновен ли князь? Для Каляева да,
для вдовы князя нет. Это оценочное понятие **по замыслу** — ровно «дыра» из
исходных заметок (§6).

**Нагрузка J3.** У слепого агента было четыре типа пробела: неполный вопрос,
размытость, вымысел не фиксирует, мало свидетельств. Ни один не подходит:
«невинный» не размытый и не неизвестный, он **зависит от ветки**. Нужен
**пятый тип: оценочный по замыслу**. Он снимается не данными и не порогом, а
выбором ветки:

```
gap(term: innocent, type: evaluative_by_design, resolved_by: branch)
```

Это не новый примитив, а новый тип в пункте 7. Заодно так соединяются две
линии: «дыры» исходных заметок и типизированные пробелы слепого прогона.

## 7. Веса меняются во времени

Дора к концу пьесы просит бомбу для себя. Её веса сдвинулись после казни
Каляева: из «границы» она переходит к «и я заплачу жизнью». В метаядре это
две записи `holds` в ветке `dora`, с разным временем действия (время — ось
плоскости, Ньютон, N9). Новое не нужно. Но «почему сдвинулись» (горе, любовь)
— описательный факт о Доре, а не норма.

## Итог казуса

**v0 выдержало первый моральный казус без новых примитивов.** Добавился один
тип пробела.

Критерии H14:

| Критерий | Итог |
| --- | --- |
| (a) выразимость | ✓ |
| (b) воспроизведение решений | ✓ для a1 и a2. Тюрьма — ✗ на весах по сцене, ✓ на весах из теории |
| (c) локализация конфликта | ✓, выведена |
| (d) сдвиг при смене морали | ✓: смена ветки (Степан или Каляев) предсказуемо меняет решение в a1 и не меняет в a2 |
| (e) нет утечки «есть → должно» | ✓, проверено на `bad` |
| (f) объявленное против фактического основания | не проверялось, это казус для «Постороннего» |

**Главный вывод:** механизм, на котором держится мораль, — тот же, что
держал физику и биологию. Плоскость (ветка как ось точки зрения), строгое
основание как граница, отменяемое как компромисс. Казус проверил ядро. А
метод снятия весов казус провалил, пока веса брались из сцены, и это
содержательный результат, а не неудача.

**Оговорка прежняя:** казус писал помощник.
