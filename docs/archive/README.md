# Архив

Документы проекта до чистого листа (фаза Ф0, [план](../plan.md)): контракт,
гипотезы H0–H76, казусы, уроки, разборы, отчёты о реализации. Пути внутри
архива сохранены, поэтому ссылки между архивными документами работают, а
ссылки на живые документы (`decisions.md`, `origin/` и т. п.) — нет.

Справочно. Архив не входит в обязательное чтение и не задаёт ни шагов, ни
приёмки: документ отсюда открывается только по прямому слову автора.

Код прошлого — в метке `legacy-v0` (`git show legacy-v0:<путь>`); по
[принципам](../principles.md), п. 11, он не используется ни как материал, ни
как эталон для сверки.
