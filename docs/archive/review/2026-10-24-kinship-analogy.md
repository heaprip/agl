# Аналогия на родстве: признаки — отношения (H51), 2026-10-24

Вторая проверка H51 после провала на гликолизе
([разбор](2026-10-24-analogy.md): 0 из 6). Там пропорция строилась по
признакам веществ, и это было первое предупреждение Гентнер: сопоставлять
надо отношения. Здесь понятие родства — граф отношений (нормальная форма до
`parenthood`, `marriage`, `female`, `male`), и сравниваются графы.

```sh
cargo run --release --example kinship_analogy          # итог
AGL_SHOW=1 cargo run --release --example kinship_analogy   # с кандидатами
```

## Что объявлено до прогона

Записано в H51 и закоммичено до первого запуска (коммит 6bf4eef).

- Отложенные — листовые понятия `cases/kinship.agl`: одно определение, без
  плоскости, не используются в других понятиях. Их 19. Каждое по очереди
  удаляется из программы.
- Правка — замена одного атома нормальной формы атомом примитивного отношения
  над теми же переменными: `female(?x)` → `male(?x)`, разворот `parenthood`,
  `parenthood` → `marriage`.
- Правка, переводящая существующее A в существующее C, — пара A : C. Та же
  правка над B даёт кандидата D: A : C :: B : D (пропорция Аристотеля;
  Miclet, Prade 2009).
- Кандидаты, не равные существующим понятиям, ранжируются по сумме
  подтверждений: за каждый путь (B, правка) — число пар A : C с этой правкой.
  Это систематичность по Гентнер: правка, которая много где переводит одно
  понятие в другое, весит больше.
- Успех для понятия — равный ему кандидат (та же нормальная форма) в первых
  трёх. **Успех опыта — не меньше двух третей**, то есть 13 из 19.

## Почему так

Разбор после прогона; это объяснение, а не пересмотр критерия.

1. **Впереди всегда одни и те же четыре кандидата** — пробелы самого казуса,
   а не удалённое понятие. Шесть промахов (места 4–5) проиграли только им.
   Если не считать их, в первой тройке было бы 15 из 19 — но критерий
   объявлен без такой оговорки, и подгонять его после прогона нельзя.
2. **Не предложены три понятия, и это ожидалось.** `male_cousin` — это
   `cousin` плюс атом `male`: правка заменяет, но не добавляет. `grandson` —
   в казусе нет внучки, переводить не из чего. `brother_mother` — нет
   «матери сестры». У аналогии должен быть сосед, иначе переносить нечего
   (это и предупреждение Бэкона: искать по соседству).
3. **`mother_husband` (отчим) — место 114**: его пара `father_wife`
   (мачеха) в казусе не определена, и перевести в него почти не из чего.

## Что предлагает аналогия на целом казусе

Ничего не удалено, первые восемь кандидатов:

| вес | что это | откуда |
| ---: | --- | --- |
| 32 | жена тёти | brother : sister :: aunt_husband : D |
| 32 | муж дяди | aunt_blood : uncle_blood :: aunt_husband : D |
| 23 | сестра жены — **свояченица** | brother : sister :: wife_brother : D |
| 23 | сестра мужа — **золовка** | brother : sister :: husband_brother : D |
| 19 | мужчина, у которого с ego общий ребёнок | child : parent :: grandfather : D |
| 17 | муж жены | child : spouse :: daughter_husband : D |
| 16 | жена матери | brother : sister :: mother_husband : D |
| 16 | жена сестры | brother : sister :: sister_husband : D |

Это то, чего H51 и хотела: «между этими двумя чего-то не хватает в
сравнении с другими». Свояченица и золовка — настоящие русские термины,
которых в казусе нет; «отец моего ребёнка» — настоящее отношение без
отдельного слова. Однополые браки и «муж жены» структура не запрещает: в
казусе нет утверждения, что брак — между мужчиной и женщиной и у человека
один супруг. Фильтр здесь — не аналогия, а знание о культуре, то есть норма
в своей плоскости (`forbid`, решение о нормах — за автором). Аналогия
предлагает, ядро проверяет то, что ему сказано.

## Сравнение с гликолизом

| | гликолиз | родство |
| --- | ---: | ---: |
| что сравнивалось | признаки веществ (классы ChEBI) | графы отношений |
| в первой тройке | 0 из 6 | 9 из 19 |
| предложено вообще | 1 из 6 | 16 из 19 |

Переход от признаков к отношениям — то, что советовала Гентнер, — дал
разницу. Но мера ранжирования снова оказалась решающей: систематичность
подняла настоящие пробелы казуса выше удалённых понятий. Это опять
предупреждение Канта — мера сходства задаётся, а не выводится.

## Дальше, на выбор автора

- Правки «добавить атом» (тогда найдутся `male_cousin` и составные).
- Ранжирование: штрафовать кандидатов, общих для всех прогонов, или
  предлагать списком «пробелов казуса» отдельно от проверки.
- Норма брака в казусе родства как плоскость (`forbid`) — и посмотреть,
  сколько кандидатов она снимет.
