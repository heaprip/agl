# Присоединение корня по Коши: шаг 2 лестницы H57, 2026-10-24

Критерий объявлен до прогона (H57, «Шаг 2», коммит f2b6a95). Здесь только
вход и выход; ход поиска пересчитывается по seed (`AGL_TRACE=1`).

## Вход

- Казус `cases/discovery/cauchy.agl`: уравнение Бомбелли и формула Кардано;
  элемент — многочлен a + bX (`coef(p, deg, c)`); умножение — закон
  распределения (произведение Коши, агрегат `sum` по i + j = k); приведение
  по модулю X² − s (Xᵐ = sʰXʳ, m = r + 2h). Правила умножения пар нет, s не
  задано.
- Генератор `examples/cauchy.rs`: читает аномалию и подкоренное d = −121 из
  вывода ядра; кандидаты s = d/k² (k² | d) — −121 и −1 — и контрольные
  s = 0, s = +1; по плоскости на кандидата; элементы |a|, |b| ≤ 11 (529)
  пачками по 50 в порядке от seed; затем законы на 40 парах от seed (из них
  10 с b = 0), в обоих порядках.
- Тест `tests/discovery.rs`: все 529 элементов, все четыре плоскости, 625
  пар-проб; независимость от перестановки утверждений.

```sh
cargo run --release --example cauchy -- 1         # итог
AGL_TRACE=1 cargo run --release --example cauchy  # ход поиска
```

## Толкование помощника

- Правило (ac − bd, ad + bc) в казусе не записано: ядро получило его из
  закона распределения и X² = −1. В тесте сверено для любого s:
  (ac + s·bd, ad + bc).
- Отбирает аномалия, а не законы. Все четыре кандидата переместительны и
  консервативны — так и ожидалось: факторкольцо многочленов таково по
  построению. Это урок Гана: перманентность не выбирает расширение.
- s = 0 и s = +1 — непротиворечивые теории, в которых √−121 **нет**. Это
  маленький пример различия Фреге: «не противоречит» не значит «существует»
  (подробнее — H59).
- s = −121 и s = −1 дают одно и то же поле (X = 11i). Целочисленный поиск
  видит корни только во втором: 2 ± X/11 не целые. Предпочтение s = −1 —
  следствие пространства поиска, а не понимания.

## Чего опыт не показывает

- Правило выведено на конечной выборке, а не символьно: ядро считает числа,
  не формулы.
- Приём «вычислять по модулю нерешённого уравнения» дан в казусе; генератор
  выбирает только s, и кандидатов немного.
- Новые элементы называет генератор (H58, вариант а); ядро их не создаёт.
- Общность (шаг 3: отрицательные, дроби, √2 тем же механизмом) не
  проверялась.
