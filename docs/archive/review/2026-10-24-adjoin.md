# Один приём присоединения на четыре расширения: шаг 3 лестницы H57, 2026-10-24

Критерий объявлен до прогона (H57, «Шаг 3», коммит 3d8a7a7). Библиотека
заморожена до слепой проверки (коммит f6cb9dc); задачи √2 и i написаны и
прогнаны после неё, библиотека после заморозки не менялась.

## Вход

- Библиотека `cases/lib/adjoin.agl`: элемент a + bX; произведение — закон
  распределения; X удовлетворяет тому уравнению, которое не решилось,
  L(X) = R(X); равенство — по модулю M = L − R: P ≡ 0, если P + u·M = 0 для
  множителя u = k₀ + k₁X, |kᵢ| ≤ 5.
- Задачи `cases/discovery/adjoin/` — только уравнение и старая область:
  `negatives` (x + 5 = 3, натуральные 0…8), `fractions` (3x = 1, целые
  −4…4); контрольные `divide_by_zero` (0·x = 1), `square_four` (x² = 4);
  слепые `sqrt_two` (x² = 2), `imaginary` (x² = −1).
- Генератор `examples/adjoin.rs`: старые элементы (b = 0) → аномалия →
  плоскость, где присоединено несработавшее уравнение; 81 элемент, 121
  множитель, около 1730 различных проб от seed. Флаг `force` присоединяет
  без аномалии (для контрольной x² = 4).
- Тест `tests/discovery.rs`: те же задачи с пробами |a|, |b| ≤ 2 (625 пар),
  независимость от перестановки.

```sh
cargo run --release --example adjoin -- cases/discovery/adjoin/imaginary.agl 1
cargo run --release --example adjoin -- cases/discovery/adjoin/square_four.agl 1 force
```

## Ошибка, найденная по ходу (до заморозки)

Первый прогон на отрицательных дал лишнее «решение» 5 + X (= 3). Причина:
агрегат суммирует **различные** решения (так задано в poc ради
детерминизма), и два равных слагаемых из разных источников — 5 из
уравнения и 1·5 из подстановки — слились в одно. Исправлено меткой
источника у слагаемых. Ловушка общая для всех казусов с `sum`: слагаемые
нужно различать ролями.

## Толкование помощника

- Один и тот же приём, без правок, дал отрицательные, часть дробей, √2 и i,
  и отверг деление на ноль. Это ответ на главный вопрос уровня 3: приём не
  подогнан под i.
- Почему 1 : 0 не присоединяют — видно в ядре: присоединение склеивает
  старые числа (с M = −1 любые два числа равны «с точностью до кратного»).
- «Решение есть» — по построению; содержательны пункты (2) и (3).
- Отрицательные и дроби в истории вводили иначе — парами с равенством
  крест-накрест (группа Гротендика, поле частных). Присоединение корня 3x =
  1 даёт Z[1/3], не все дроби; для 1 : 5 понадобится ещё одно
  присоединение. Ядро это покажет само, но мы не проверяли.

## Чего опыт не показывает

- Приём дан, а не найден.
- Равенство проверяется поиском множителя в конечной выборке: ядро
  подтверждает равенство, но «не равно» — это «не нашли». В этих задачах
  все нулевые элементы выборки находятся множителем |k| ≤ 5 (проверено на
  бумаге), поэтому ложных делителей нуля нет; на больших выборках может
  понадобиться больший K.
- Арифметика ядра — числа с плавающей точкой: в метаязыке отрицательные и
  дроби уже есть. «Старая область» — только то, какие элементы назвал
  генератор.
- Шаг 2 (возврат к корню 4 по Кардано) на этой библиотеке не повторялся.
