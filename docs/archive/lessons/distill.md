# Дистилляция реализаций: изоморфизм, задание соотношениями, вид

Сверка перед шагом 5 лестницы H57 (2026-10-25), по слову автора: геометрия —
не вход, а вид найденной структуры; много реализаций — повод для дистилляции.
Пометки — как в [discovery](discovery.md): **[сверено]** — по первоисточнику или
его прямой цитате; **[по вторичному]** — по справочнику; **[по памяти]** — не
сверено.

## 1. Одна структура — много реализаций

- **Классификация двумерных.** С точностью до изоморфизма вещественных
  двумерных алгебр с единицей ровно три: комплексные (квадрат новой единицы
  −1), расщеплённые комплексные (+1) и дуальные (0); все переместительны и
  сочетательны [по вторичному: Wikipedia, «Hypercomplex number»]. Для agl:
  кандидаты s = −1, +1, 0 шага Коши — это ровно три класса; аномалию
  Бомбелли решает только первый.
- **Фробениус** (1877): всякая конечномерная сочетательная алгебра с
  делением над вещественными изоморфна ℝ, ℂ или кватернионам ℍ [по
  вторичному: Wikipedia, «Frobenius theorem (real division algebras)»; там же
  статья Фробениуса датирована 1878]. Для agl: две таблицы шага 4
  (кватернионы и зеркало) — обе сочетательные с делением размерности 4,
  значит **обязаны** быть одной структурой; ядро должно найти явное
  соответствие.
- **Бикомплексные / тессарины.** Тессарины — Cockle, 1848; бикомплексные —
  Segre, 1892; это одна алгебра, изоморфная ℂ ⊕ ℂ: переместительна,
  сочетательна, с делителями нуля и идемпотентами (1 ∓ hi)/2 [по вторичному:
  Wikipedia, «Bicomplex number»]. **Поправка помощника:** у них есть
  мультипликативная норма, но комплекснозначная, (w, z) ↦ w² + z² —
  бикомплексные числа — композиционная алгебра. Верно другое: положительно
  определённой вещественной мультипликативной нормы у них нет — при
  делителях нуля xy = 0 из N(xy) = N(x)N(y) вышло бы N(x) = 0 или N(y) = 0
  (вывод помощника из определений).
- **Дуальные над комплексными.** Переместительная алгебра ℂ[ε]/(ε²), ε² = 0 —
  то, что нашла абляция шага 4 («с нулём»). **Поправка имени:**
  «dual-complex numbers» в литературе — другое, некоммутативные «плоские
  кватернионы»; ℂ[x]/(x²) там названа отдельно как переместительная [по
  вторичному: Wikipedia, «Dual-complex number»]. В agl называть «дуальные
  числа над комплексными».

## 2. Что отличает структуры

- Изоморфизм — линейная замена базиса, сохраняющая умножение. Сохраняются
  **свойства без базиса**: переместительность, сочетательность, есть ли
  делители нуля, есть ли x ≠ 0 с x² = 0. Норма «сумма квадратов
  коэффициентов» привязана к базису и при общей замене меняется — её нельзя
  брать как признак различия (вывод помощника из определений).
- Перебор соответствий только среди перестановок единиц со знаками:
  **найденное** соответствие доказывает изоморфизм; **ненайденное** не
  доказывает ничего — различие доказывают свойства без базиса.
- Ядро на выборке показывает **существование** (нашёлся делитель нуля);
  **отсутствие** на выборке не доказывается — его дают теоремы выше.

## 3. Задание образующими и соотношениями

- Гамильтон, 16 октября 1843, Брум-бридж: «the fundamental formula with the
  symbols, i, j, k», i² = j² = k² = ijk = −1 [сверено: письмо Гамильтона,
  TCD].
- Алгебра кватернионов над полем F задаётся образующими i, j с
  соотношениями i² = a, j² = b, ij = −ji (k = ij); Гамильтон — a = b = −1
  [по вторичному: Wikipedia, «Quaternion algebra»]. Отсюда k² = −1 и
  ijk = −1 — вывод из соотношений.

## 4. Вид: структура, действующая на себе

- **Кэли** (1854): всякая группа изоморфна группе перестановок самой себя
  (x ↦ gx); приписывают также Жордану (1870) и Дику (1882) [по вторичному:
  Wikipedia, «Cayley's theorem»].
- **Клейн**, Эрлангенская программа, 1872, «Vergleichende Betrachtungen über
  neuere geometrische Forschungen»: каждой геометрии — своя группа
  преобразований, её предмет — инварианты [по вторичному: Wikipedia,
  «Erlangen program»]. Это и есть «геометрия — вид структуры».
- **Повороты сопряжением.** Кэли, Phil. Mag. 1845 (т. 26, с. 141–145):
  формулы Эйлера — Родрига через кватернионы; явная запись
  ix′ + jy′ + kz′ = Π(ix + jy + kz)Π⁻¹ — в его позднейшем примечании к той же
  статье; Гамильтон признал за Кэли первенство печати [по вторичному: сводка
  по поиску; полный текст 1845 не прочитан]. Родриг вывел формулу композиции
  поворотов в 1840 [по вторичному: Wikipedia, «Quaternions and spatial
  rotation»].
- **Двойное накрытие.** q и −q дают один и тот же поворот: сопряжение
  квадратично по q, знак сокращается [по вторичному: там же]. Для agl:
  вид «повороты» сопоставляет каждому повороту **два** единичных
  кватерниона — это свойство вида, ядро должно его показать, а не потерять.
- Композиция поворотов зависит от порядка — непереместительность
  умножения [по вторичному: там же].

## 5. Что это меняет в шаге 5

| Ожидание | Опора |

| кватернионы и зеркало — одна структура | Фробениус; явное соответствие ищет ядро |
| варианты бикомплексных — одна структура (ℂ ⊕ ℂ) | Segre, Cockle |
| варианты «с нулём» — одна структура ℂ[ε]/(ε²) | определения |
| три структуры попарно различны | свойства без базиса: переместительность, делители нуля, x² = 0 |

| вид «повороты»: q·v·q⁻¹ сохраняет норму, q и −q — один поворот, композиция не переместительна | Кэли 1845, Родриг 1840 |
| у бикомплексных и ℂ[ε] вида «повороты» с положительной нормой нет | делители нуля (вывод из определений) |
