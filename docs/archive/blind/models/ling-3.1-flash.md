# Отчёт: минимальная формальная нотация для представления смысла казусов

---

## 1. Итоговый набор примитивов и семантических правил

### 1.1 Примитивы

| № | Примитив | Обозначение | Смысл |
|---|---------|-------------|-------|
| P1 | Сущность | `a`, `b`, `s`, `man`… | Всё, что может быть обозначено константой и выступать аргументом отношения |
| P2 | Отношение | `R(x, y, …)` | Именованная связь между сущностями (и, по SR2, формулами) |
| P3 | Отрицание | `¬φ` | Отказ от формулы |
| P4 | Конъюнкция | `φ ∧ ψ` | Совместное выполнение двух формул |
| P5 | Квантор всеобщности | `∀x: φ(x)` | Формула верна для всех x |
| P6 | Квантор существования | `∃x: φ(x)` | Существует x, для которого формула верна |
| P7 | Временной индекс | `R(x,y)@t` | Привязка атомарного утверждения к моменту (или интервалу) времени |
| P8 | Источниковый тег | `[G]`, `[I]`, `[D]`, `[U]` | Метка эпистемического статуса утверждения: дано текстом/сценарием, выведено аналитиком, получено по определённому правилу, не определено имеющейся информацией |

### 1.2 Семантические правила

| № | Правило | Формулировка |
|---|---------|-------------|
| SR1 | Критериальная относительность тождества | Если C₁ ≠ C₂, то `same[C₁](X,Y)` и `same[C₂](X,Z)` логически независимы: ни одно не влечёт и не противоречит другому, даже если Y ≠ Z. |
| SR2 | Формулы как аргументы | Отношения речевых актов и установок (`says`, `believes`, `wants`, `understands` и т. п.) принимают формулу в качестве одного из аргументов. Это типовое исключение: вторая позиция этих отношений принимает не только сущности, но и формулы. |
| SR3 | Открытый мир (отсутствие ≠ отрицание) | `absent(text, X)` (текст не содержит утверждений о X) не влечёт `¬X` и не влечёт `[U]: X`. Текст может молчать о X, но X может быть установлено выводом из других утверждений текста. |
| SR4 | Распространение тегов | Если утверждение B выведено из посылок с тегом `[G]` (аналитиком), B получает тег `[I]`. Если B получено по определённому правилу системы — `[D]`. |

### 1.3 Определённые сокращения (не примитивы)

| № | Сокращение | Определение |
|---|-----------|-------------|
| D1 | `absent(text, X)` | `¬∃φ: states(text, φ) ∧ about(φ, X)` — текст не содержит утверждения о X |
| D2 | `sincere(a, φ)` | `says(a, φ) ∧ believes(a, φ)` |
| D3 | `insincere(a, φ)` | `says(a, φ) ∧ ¬believes(a, φ)` |
| D4 | `same[C](X, Y)` | Синтаксический сахар для `same(X, Y, C)` |
| D5 | `φ → ψ` | `¬(φ ∧ ¬ψ)` (определимо из P3, P4) |
| D6 | `φ ∨ ψ` | `¬(¬φ ∧ ¬ψ)` (определимо из P3, P4) |
| D7 | `φ ↔ ψ` | `(φ → ψ) ∧ (ψ → φ)` (определимо из D5, P4) |

### 1.4 Метауровневое требование

**Прозрачность обоснования (R1):** каждый ответ на вопрос должен сопровождаться множеством идентификаторов утверждений и семантических правил, на которых он держится.

### 2.1 Казус 1: Корабль Тесея (с продолжением Гоббса)

#### Сущности

`s` — исходный корабль Тесея; `S_A` — непрерывно поддерживаемый корабль (все доски заменены); `S_B` — корабль, собранный из выброшенных досок; `p₁ … pₙ` — исходные доски; `p₁' … pₙ'` — заменяющие доски; `f_s` — форма (конструкция) исходного корабля; `c_mat`, `c_form`, `c_cont`, `c_leg`, `c_rit` — критерии: материал, форма, непрерывность, юридическое владение, ритуальная роль; `Ath` — афиняне; `coll` — собиратель; `t₀` — начальный момент; `t₁ … t_N` — моменты последовательных замен; `t_f` — момент, когда все доски заменены; `t_r` — момент сборки S_B.

#### Утверждения

**Дано (исходный сценарий):**

```
A1  [G]: ∀i: part(pᵢ, s)@t₀
A2  [G]: ∀k∈{1..N}: ∃i: (¬part(pᵢ, S_A)@tₖ) ∧ (part(pᵢ', S_A)@tₖ)
A3  [G]: ∀i: (¬part(pᵢ, S_A)@t_f) ∧ (part(pᵢ', S_A)@t_f)
A4  [G]: continuous(S_A, s, t₀, t_f)
A5  [G]: ∀t∈[t₀, t_f]: has_form(S_A, f_s)@t
A6  [G]: ∃coll: collects(coll, {p₁,…,pₙ}) ∧ builds(coll, S_B, {p₁,…,pₙ})@t_r
A7  [G]: ∀i: part(pᵢ, S_B)@t_r
A8  [G]: has_form(S_B, f_s)@t_r
A9  [G]: ¬continuous(S_B, s, t₀, t_r)
A10 [G]: ∃t_r: exists(S_A)@t_r ∧ exists(S_B)@t_r   ← оба существуют одновременно (Гоббс)
```

**Выводы (инференции аналитика):**

```
A11 [I]: same[c_mat](S_B, s)
         Основания: A7 (S_B состоит из исходных досок)

A12 [I]: same[c_form](S_A, s)
         Основания: A5 (форма непрерывно поддерживалась)
         Замечание: S_B также имеет форму f_s (A8), но форма была прервана
         (разборка → сборка). Если «форма» = текущее расположение частей,
         оба подходят; если «форма» = непрерывно поддерживаемое расположение,
         только S_A. Эта неоднозначность отмечена, не разрешена.

A13 [I]: same[c_cont](S_A, s)
         Основания: A4

A14 [U]: same[c_leg](?, s)
         Основания: absent(сценарий, юридические_факты) — по SR3, молчание ≠ отрицание

A15 [U]: same[c_rit](?, s)
         Основания: absent(сценарий, факты_о_признании) — зависит от социального
         признания, которое не задано
```

**Производные (по правилам системы):**

```
A16 [D]: ¬contradicts(A11, A12)    — по SR1 (разные критерии)
A17 [D]: ¬contradicts(A11, A13)    — по SR1
A18 [D]: ¬contradicts(A12, A13)    — по SR1
A19 [D]: ¬∃p: (original(p) ∧ part(p, S_A)@t_f)   — из A1, A2, A3
```

**Момент перехода:**

```
A20 [I]: ¬∃t: moment_of_change(s, t, c_form)
         Основания: A5 (форма сохранялась на всём промежутке)

A21 [I]: ¬∃t: moment_of_change(s, t, c_cont)
         Основания: A4 (непрерывность сохранялась)

A22 [I]: under c_mat — вопрос о «моменте» некорректно поставлен:
         каждая замена доски — бесконечно малое изменение материала;
         резкого порога нет. Это проблема сорит.
         Основания: A2 (постепенность замены)
```

#### Ответы на вопросы

**Q1: Какой из двух кораблей — корабль Тесея?**

Ответ: зависит от критерия. По материалу — S_B (A11). По форме — S_A (A12, при интерпретации «непрерывно поддерживаемой формы»). По непрерывности — S_A (A13). По юридическому владению и ритуальной роли — не определено сценарием (A14, A15).

*Основания:* {A7, A5, A4, A11, A12, A13, A14, A15, SR1}

**Q2: Зависит ли ответ от критерия?**

Ответ: да, фундаментально. Разные критерии дают разные ответы (A11 vs. A12, A13). Критерии c_leg и c_rit не определены сценарием.

*Основания:* {A11, A12, A13, A14, A15, SR1}

**Q3: Есть ли момент, когда корабль «перестал быть» тем же?**

Ответ: по форме и непрерывности — нет (A20, A21). По материалу — нет резкого момента; изменение постепенное (A22). Сам вопрос предполагает существование порога, который при данных критериях отсутствует. Это не решённый вопрос, а некорректно поставленный (при большинстве критериев).

*Основания:* {A5, A4, A2, A20, A21, A22}

**Q4: Противоречат ли друг другу ответы по разным критериям?**

Ответ: нет — по SR1. Утверждения `same[c_mat](S_B, s)` и `same[c_form](S_A, s)` логически независимы, так как индексированы разными критериями (A16, A17, A18). Это **кажущееся** противоречие: оно возникает только если предположить, что тождество абсолютно (не зависит от критерия). При этом допущении ответы действительно конфликтовали бы — но это метафизическая позиция, а не логический факт. Система SR1 принимает критериальную относительность, и при этом наличии противоречия нет.

*Основания:* {A11, A12, A13, A16, A17, A18, SR1}

**Замечание о практическом конфликте.** Отсутствие логического противоречия не снимает **практической** проблемы: если нужно решить, какой корабль выставить в музей, требуется выбрать критерий — это решение социальное, а не логическое. Система может зафиксировать это как `decision_problem(выбор_критерия)`, но не может его разрешить.

### 2.2 Казус 2: Хемингуэй, «Холмы как белые слоны»

#### Сущности

`text` — текст рассказа; `man` — мужчина (американец); `woman` — женщина (девушка); `op` — неназванная операция; `station` — железнодорожная станция; `hills` — холмы через долину; `Ebro` — река (долина Эбро).

#### Утверждения

**Что текст говорит [G]:**

```
A1  [G]: setting(text, station_in_Spain)
A2  [G]: characters(text, {man, woman})
A3  [G]: refers(text, op) ∧ ¬names(text, op)
         Текст ссылается на операцию, но не называет её по имени.
A4  [G]: says(man, operation_is_simple, to=woman)
         Мужчина характеризует операцию как «ужасно простую» (точная
         формулировка не приводится — отмечаю неуверенность в деталях
         wording).
A5  [G]: says(man, respects_her_choice, to=woman)
         Мужчина говорит нечто вроде «я не хочу, чтобы ты делала то,
         чего не хочешь». Точная формулировка неуверенна.
A6  [G]: says(man, things_will_be_fine_afterward, to=woman)
         Мужчина утверждает, что после всё будет хорошо, «как прежде».
A7  [G]: mentions(text, hills) ∧ mentions(text, white_elephants)
         Женщина сравнивает холмы с белыми слонами.
A8  [G]: at_end(text): woman_says_feels_fine; man_goes_for_bags
         К концу женщина говорит, что чувствует себя хорошо; мужчина
         уходит за багажом.
A9  [G]: absent(text, word «abortion»)
         Слово «аборт» (или эквивалент) в тексте не встречается.
```

**Что читатель выводит [I]:**

```
A10 [I]: op = abortion
         Основания: A3 (операция упомянута, но не названа), A4
         (минимизация), A6 (утверждение, что после всё будет
         «как прежде»), A7 (образ белого слона — культурный
         символ нежелательного бремени), общий контекст напряжённого
         разговора пары. Вывод сильный, но не текстуальный.

A11 [I]: wants(man, woman_has(op))
         Основания: A4, A6, паттерн диалога — мужчина систематически
         аргументирует в пользу операции.

A12 [I]: pattern(man, pressure(woman, op))
         Основания: A4, A5, A6 — совокупность высказываний
         конституирует давление, несмотря на A5.

A13 [I]: gap(says(man, respects_her_choice), does(man, pressure(woman, op)))
         Между заявленной позицией (A5) и поведенческим паттерном (A12)
         — разрыв.
         Это НЕ логическое противоречие: says и does — разные предикаты.
         Человек может искренне считать, что не давит, при этом
         давя.

A14 [I]: believes(woman, op_will_change_things)
         Основания: вопросы женщины о «после», её настойчивость
         в обсуждении последствий. Неуверенность в конкретных
         репликах — отмечаю.

A15 [I]: wants(woman, maintain_relationship)
         Основания: готовность женщины продолжать разговор,
         её вопрос «будет ли потом всё хорошо» (интерпретация).

A16 [I]: possible_interpretations(woman's_desire_regarding_op,
         {wants_op, wants_¬op, ambivalent})
         Текст совместим с несколькими прочтениями желания женщины.

A17 [I]: symbolizes(hills/white_elephants, unwanted_situation)
         Основания: A7, культурный контекст. Это одна из
         литературных интерпретаций, не единственная.
```

**Что текст оставляет неопределённым [U]:**

```
A18 [U]: wants(woman, op)
         Желание женщины относительно операции не определено текстом.
         Основания: A16 (множественные возможные прочтения).

A19 [U]: believes(man, ¬pressure(woman, op))
         Осознаёт ли мужчина, что давит? Текст не даёт прямого
         доступа к его рефлексии.

A20 [U]: decides(woman, op)
         Что женщина решит — не определено.

A21 [U]: outcome(text)
         Итог ситуации не определён.

A22 [U]: conscious_intention(man, manipulate)
         Сознательно ли мужчина манипулирует? Не определено.
```

**Анализ искренности:**

```
A23 [I]: sincere(man, utterance_A5, scope=local) — возможно
         В момент произнесения фраза может быть искренней.
         Основания: A5.

A24 [I]: ¬sincere(man, pattern_of_behavior, scope=global) — вероятно
         Совокупность поведения (A12) противоречит заявленной позиции
         (A5) в глобальном масштабе.
         Основания: A5, A12, A13.

A25 [I]: possible_interpretations(sincerity_of_man,
         {consciously_insincere, self_deceived, sincere_but_ineffective})
         Текст не разрешает выбор между этими вариантами.
         Основания: A19, A22, A23, A24.
```

**Проверка противоречий:**

```
A26 [D]: ¬contradicts(A5, A12)
         «Говорит, что не хочет заставлять» и «оказывает давление»
         не противоречат друг другу логически: разные предикаты
         (says vs. pattern). Противоречие было бы только при
         дополнительной посылке says(a, ¬wants(a, force)) →
         ¬does(a, pressure), которой нет.

A27 [D]: ¬contradicts(A11, A5)
         «Хочет, чтобы она сделала операцию» и «говорит, что
         не хочет заставлять» — совместимы: он может хотеть
         результата, считая, что оставляет ей выбор.
```

#### Ответы на вопросы

**Q1: О какой операции идёт речь и откуда это известно?**

Ответ: почти наверняка об аборте (A10). Это **вывод**, а не утверждение текста. Текст лишь ссылается на операцию, не называя её (A3, A9). Основания для вывода: минимизация процедуры (A4), утверждение, что после всё будет «как прежде» (A6), образ белого слона (A7), общий контекст. Статус: `[I]`, не `[G]`.

*Основания:* {A3, A4, A6, A7, A9, A10, SR3}

**Q2: Чего хочет каждый персонаж?**

Мужчина: хочет, чтобы женщина сделала операцию (A11). Основания: паттерн аргументации (A4, A6, A12).

Женщина: хочет сохранить отношения (A15) — вывод. Её желание относительно самой операции — неопределено (A18). Текст совместим с несколькими прочтениями (A16).

*Основания:* {A4, A6, A11, A12, A15, A16, A18}

**Q3: Искренна ли фраза мужчины?**

Ответ: многослойно. Локально (в момент произнесения) — возможно искренна (A23). Глобально (в контексте поведенческого паттерна) — эффект неискренен (A24). Осознаёт ли мужчина разрыв — неопределено (A19, A22). Текст не разрешает выбор между интерпретациями (A25).

*Основания:* {A5, A12, A13, A19, A22, A23, A24, A25}

**Q4: Что решено в конце и решено ли вообще?**

Ответ: не решено (A20, A21). Женщина говорит «чувствую себя хорошо» (A8) — это неоднозначно: может быть принятием, отклонением темы, или констатацией физического состояния. Мужчина уходит за багажом — они садятся на поезд, но решение об операции не принято (или, по крайней мере, не показано).

*Основания:* {A8, A20, A21}

**Разделение: текст говорит / читатель выводит / текст оставляет неопределённым:**

| Категория | Утверждения |
|-----------|------------|
| Текст говорит [G] | A1–A9 |
| Читатель выводит [I] | A10–A17, A23–A25 |
| Неопределено [U] | A18–A22 |

### 2.3 Казус 3: Хемингуэй, «Убийцы»

#### Сущности

`text` — текст рассказа; `Nick` — Ник Адамс; `Ole` — Оле Андресон; `Al`, `Max` — убийцы; `Sam` — повар; `George` — владелец закусочной (за стойкой); `diner` — закусочная в Саммите; `boarding_house` — пансион, где живёт Оле.

#### Утверждения

**Дано [G]:**

```
A1  [G]: setting(text, diner_in_Summit)
A2  [G]: characters(text, {Al, Max, Nick, Ole, Sam, George})
A3  [G]: enters(Al, Max, diner) ∧ asks(Al, Max, about=Ole)
A4  [G]: ties_up(Al, Max, Sam)
A5  [G]: waits(Al, Max, for=Ole)@diner
A6  [G]: ¬appears(Ole)@diner
A7  [G]: leaves(Al, Max)
A8  [G]: goes_to(Nick, boarding_house) — Ник идёт предупредить Оле
A9  [G]: finds(Nick, Ole)@boarding_house
A10 [G]: lying(Ole, on_bed, fully_dressed, facing_wall)
A11 [G]: says(Ole, ¬will_run) — Оле говорит, что не будет бежать
         (точная формулировка неуверенна; возможно, он выражает
         это менее прямо, но смысл передаётся)
A12 [G]: returns(Nick, diner)
A13 [G]: says(Nick, will_leave_town, to=George)
A14 [G]: says(George, nothing_can_be_done, to=Nick)
         (или близкий по смыслу ответ — точная формулировка неуверенна)
A15 [G]: absent(text, reason_for_killing)
A16 [G]: absent(text, identity_of_employer)
A17 [G]: absent(text, outcome_for_Ole)
```

**Выводы [I]:**

```
A18 [I]: wants(Al_Max, kill(Ole))
         Основания: A3, A5, A7 — поведение (пришли искать Оле,
         ждали, ушли). Наличие оружия — неуверен, отмечаю.

A19 [I]: believes(Ole, ¬can_escape(Ole))
         Основания: A10, A11 — поза (лежит, одет, лицом к стене)
```

```
A26 [G]: absent(text, reason_for_killing)

         Текст не сообщает, кто заказал убийство.
```

**Ключевой момент — как представить отсутствие, не выдумывая:**

`absent(text, X)` — это **структурный факт о тексте**, а не утверждение о мире. По SR3: `absent(text, reason)` ≠ `¬reason`. Причина убийства может существовать в вымышленном мире рассказа; текст просто её не сообщает. Система не заполняет пробел домыслом — она фиксирует пробел как пробел.

#### Ответы на вопросы

**Q1: Почему Оле Андресон не бежит?**

Ответ: текст не называет причину прямо. Из поведения (A10, A11) выводится: он считает, что бегство невозможно или бессмысленно (A19); он принимает свою судьбу (A20); он устал (A21). Точный мотив — `[U]`: текст не даёт доступа к его внутреннему миру.

*Основания:* {A10, A11, A19, A20, A21}

**Q2: Что понял Ник и почему решает уехать?**

Ответ: Ник понял, что мир содержит бессмысленную, неизбежную насилие, которому он не может противодействовать (A22). Он решает уехать, потому что не может вынести это знание (A23). Его решение — не трусость перед конкретной опасностью, а реакция на столкновение с бессмысленностью.

*Основания:* {A9, A10, A11, A13, A14, A22, A23, A24}

**Q3: Чего текст не говорит и как представить это?**

Ответ: текст не говорит, за кого хотел убить Оле (A26), кто заказчик (A27), чем всё кончится (A28). Это представлено как `absent(text, X)` — структурный факт о тексте, не тождественный отрицанию (SR3). Умолчание, вероятно, сознательно (A29), но это вывод о намерении автора, по определению неуверенный.

*Основания:* {A15, A16, A17, A26, A27, A28, A29, SR3}

## 4. Что не выразилось или выразилось натяжкой

### 4.1 Не выразилось

1. **Вагность / сорит (Казус 1).** Вопрос «в какой момент корабль перестал быть тем же» предполагает резкий порог. Система может сказать `¬∃t: sharp_threshold(t)`, но не может выразить *природу* вагности — является ли она эпистемической (мы не знаем порога) или онтологической (порога нет). Формула `¬∃t: moment_of_change(...)` констатирует отсутствие момента, но не различает эти два случая.

2. **Степени тождества (Казус 1).** `same[C](X,Y)` бивалентно: да или нет. Не может сказать «более или менее то же». При постепенной замене досок корабль становится «менее тем же» по материалу — система не может выразить градацию.

3. **Тон, подтекст, прагматика (Казус 2).** Давление мужчины передаётся тоном, паузами, ритмом диалога. Система фиксирует пропозициональное содержание реплик и выводит паттерн давления (A12), но не может представить *как* сказано.

4. **Эмоциональная текстура (Казусы 2, 3).** Амбивалентность женщины, усталость Оле, отвращение Ника — представлены как `believes` и `wants`, но качественная сторона переживания утрачена.

5. **Сознательное художественное умолчание (Казусы 3, 4).** Система может зафиксировать `absent(text, X)` и вывести `deliberate(absent(...))`, но этот вывод — утверждение о намерении автора, по определению неустановимое с уверенностью. Система не имеет встроенного механизма для работы с неопределённостью авторского замысла.

6. **Эмоциональное воздействие текста (Казус 4).** Почему шесть слов сильны. Система может представить выстраиваемую историю (A4–A8) и разрыв между сказанным и подразумеваемым (A10), но не сам аффективный ответ читателя.

7. **Контрфактическое рассуждение (Казусы 1, 2).** «Что если бы доски не собрали заново?» «Что если бы она согласилась?» Нет контрфактического оператора.

8. **Нарративная структура (Казусы 2, 3).** Система представляет содержание, но не то, *как* рассказ организован (порядок раскрытия информации, темп, что удерживается до конца). Между тем в «Убийцах» структура (сначала убийцы, потом Ник, потом Оле) создаёт эффект.

9. **Процесс вывода читателя (Казусы 2, 4).** Система фиксирует *результат* вывода (тег [I]), но не *процесс* (абдукция, сопоставление с культурными паттернами, активация знания о стиле Хемингуэя).

10. **Ирония и недосказанность как литературный механизм (Казус 2).** «Айсберг» Хемингуэя — смысл под поверхностью. Система различает сказанное и выведенное, но не моделирует *механизм*, создающий зазор между ними.

11. **Степени уверенности (Казус 4).** «Вероятно апокрифично» — система имеет бинарные теги [I] и [U], но не имеет градации уверенности.

12. **Институциональные факты (Казус 1).** Юридическое владение и ритуальная роль зависят от социальных институтов. Система может представить их как критерии (c_leg, c_rit), но не может моделировать сами институты.

### 4.2 Выразилось натяжкой

1. **Амбивалентность (Казус 2).** `wants(woman, op) ∧ wants(woman, ¬op)` формально допустимо (это не противоречие, так как разные предикаты установки), но грубо. Настоящая амбивалентность — не два желания, а одно неустойчивое состояние. Система аппроксимирует её комбинацией [I]-выводов и [U]-тегов, но это не то же самое.

2. **Локальная vs. глобальная искренность (Казус 2).** Система может сказать `sincere(man, utterance, scope=local)` и `¬sincere(man, pattern, scope=global)`, но отношение между этими двумя уровнями (искренняя реплика внутри неискреннего паттерна) формально не моделировано.

3. **«Форма» как критерий (Казус 1).** `has_form(S_A, f_s)` и `has_form(S_B, f_s)` — оба истинны, если «форма» = текущее расположение частей. Но если «форма» = непрерывно поддерживаемое расположение, только S_A подходит. Система фиксирует эту неоднозначность (A12, замечание), но не может её разрешить — это требует уточнения самого критерия.

4. **Продолжение Гоббса — физическая деталь (Казус 1).** При сборке S_B из старых досок: сохраняют ли доски ту же форму? Подходят ли они? Это физический вопрос, который мысленный эксперимент опускает. Система не может моделировать материальные свойства досок.

5. **Пресуппозиция вопроса (Казус 1).** Вопрос «когда корабль перестал быть тем же?» пресуппонирует, что такой момент есть. Система может зафиксировать это как `presupposes(question, ∃t: moment_of_change(...))`, но у неё нет специального механизма для работы с пресуппозициями.

6. **Относится vs. называет (Казус 2).** `refers(text, op) ∧ ¬names(text, op)` — система использует два отдельных отношения, но различие между «ссылкой» и «именованием» тонко и не имеет глубокой формализации в системе.

## 5. Оценка: какие примитивы фундаментальны, а какие сводимы

### Фундаментальные (вряд ли сводимы)

- **P1 (Сущность).** Нужно, на что ссылаться. Ирредуцируемо.
- **P2 (Отношение).** Нужно говорить что-то о сущностях. Ирредуцируемо.
- **P3 (Отрицание).** Нужно отрицать. Без отрицания невозможно выразить отсутствие, противоречие, опровержение. Ирредуцируемо.
- **P4 (Конъюнкция).** Нужна для составного содержания (содержание высказывания, содержание установки). Формально сводима к другим связкам в классической логике, но в системе без дизъюнкции и импликации — не сводима. Фундаментальна в данной системе.
- **P5 (∀).** Нужна для общих утверждений. Не сводима к конечной конъюнкции при бесконечных или неопределённых областях. Фундаментальна.
- **P7 (Временной индекс).** Нужна для изменения. Формально заменима именованными отношениями (part_at_t0, part_at_t1…), но это потеря выразительности, а не истинное сведение. Фундаментальна практически.
- **P8 (Источниковый тег).** Нужна для целей (a), (b), (c). Без неё система не может различать данное, выведенное и неопределённое. Фундаментальна для данной задачи (хотя не для логики вообще).

### Возможно сводимые

- **P6 (∃).** Определимо: `∃x: φ(x)` = `¬∀x: ¬φ(x)`. Удобно, но сводимо к P3 + P5.
- **SR1 (Критериальная относительность).** Это не столько примитив, сколько философская позиция, закодированная как семантическое правило. Можно было бы принять абсолютное тождество и столкнуться с противоречиями — тогда правило не нужно, но система некорректна. SR1 — это не столько примитив, сколько разрешение философской проблемы на уровне семантики.
- **SR2 (Формулы как аргументы).** Сводимо к реификации пропозиций (представление пропозиций как сущностей с отношением `content`). Это сдвиг проблемы, а не её решение, но формально сводимо.
- **SR3 (Открытый мир).** Не правило вывода, а мета-логическое допущение. Можно рассматривать как следствие семантики тега [U] и отношения `absent`. Сводимо, но полезно сделать явным.
- **SR4 (Распространение тегов).** Сводимо к ручной аннотации. Нужно для автоматизации, не нужно для ручной работы.

### Наблюдение о минимальном ядре

Если убрать всё сводимое, минимальное ядро — это **P1, P2, P3, P4, P5, P7, P8** (7 примитивов) и **SR1** (одно семантическое правило). Всё остальное — удобство, определённые сокращения или следствия.

Интересно, что **P8 (источниковый тег)** — единственный примитив, специфичный для данной задачи (цели a, b, c). Остальные шесть — стандартная логическая инфраструктура. Это говорит о том, что главное нововведение, которое потребовалось казусам, — не логическая структура, а **эпистемическая разметка**: система должна знать, откуда берётся каждое утверждение.

## 6. Совпадения с известными системами (post hoc)

После того как решения были приняты из самих казусов, отмечаю следующие совпадения:

- **Источниковые теги [G/I/D/U]** структурно напоминают провенанс-трекинг в базах данных и эпистемическую разметку в некоторых системах эпистемической логики.
- **Критериально-индексированное тождество `same[C]`** совпадает с идеей сортально-зависимого тождества в формальной онтологии (работы Гуарино и др.) и с дискуссией об относительном тождестве (Гич, Нунан).
- **Правило SR3 (открытый мир)** — стандартное допущение в описательных логиках и семантической паутине, в противоположность замкнутому миру баз данных.
- **Различение «текст говорит / читатель выводит / неопределено»** перекликается с исследованиями текстуальной энтейлментности и с риторической структурной теорией (RST).
- **Установочные отношения (believes, wants)** — стандартны для доскастической и эпистемической логики (Хинтикка и др.).
- **Отношение `absent`** напоминает negation-as-failure в логическом программировании и open-world assumption в описательных логиках.
- **Прозрачность обоснования (R1)** перекликается с аргументационными рамками (Данг, Поллок) и логикой обоснований (Артёмова, Фиттинга).
- **Общая архитектура** (частичная информация, привязка к источнику, проверка противоречий) имеет семейственное сходство с ситуационной семантикой Барвайза и Перри, хотя я к ней не обращался.

Ни одна из этих систем не использовалась как основа. Все решения были продиктованы казусами.
