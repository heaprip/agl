# Пучки и топосы: операции теории и что из них есть в agl

Справочник к H50 и [сверке](../review/2026-10-24-sheaves.md). По каждой
операции: что она значит в теории, как читается для плоскостей и есть ли она в
ядре. Пометка **[сверено]** — определение проверено по источнику в списке
внизу; **[по памяти]** — нет. Первая версия сверки была написана целиком по
памяти; этот файл — ответ на вопрос автора, точно ли.

Пространство — все плоскости; открытая область — плоскость или объединение
плоскостей. «U» и «V» ниже — области, «p» — утверждение.

## 1. Логика областей: алгебра Гейтинга

Истинное значение утверждения в топосе пучков на пространстве — **область,
где оно верно**. Области образуют алгебру Гейтинга — логику, где закон
исключённого третьего не обязан выполняться. [сверено: nLab, Heyting algebra]

| Операция | Определение | Смысл для плоскостей | В ядре |
| --- | --- | --- | --- |
| ⊤ | всё пространство | корневая плоскость `@` | есть |
| ⊥ | пустое множество | непересекающиеся плоскости | есть: пересечение не строится |
| U ∧ V | U ∩ V | пересечение плоскостей | есть (`+` в SPEC, `a∩b`), с оговорками сверки п. 7–8 |
| U ∨ V | U ∪ V | «верно в одной из плоскостей» | **нет**: объединения плоскостей не записать |
| U ⇒ V | внутренность (дополнение U ∪ V) | «где U, там и V» | **нет** |
| ¬U | внутренность дополнения U | наибольшая область, нигде не задевающая U | **нет** как операции; соседи по умолчанию не пересекаются |

U ∨ ¬U бывает меньше всего пространства: остаётся **граница**. Для agl это
место, где утверждение не верно и не опровергнуто ни в какой окрестности, —
формальная тень «размытых границ» из H22.

## 2. Где верна формула: семантика Крипке — Жуаяля

«U ⊩ p» — «p верно на области U». Правила (для любого топоса) [сверено: nLab,
Kripke-Joyal semantics]:

| Формула | U ⊩ … тогда и только тогда, когда | Для agl |
| --- | --- | --- |
| p ∧ q | U ⊩ p и U ⊩ q | как в ядре |
| p ∨ q | U **покрыта** частями, на каждой из которых верно p или q | дизъюнкция **локальна**: можно знать «мать или отец» по частям, не зная, что именно на всей U. Тот же смысл у `cover` в понятиях; для плоскостей нет |
| p ⇒ q | на каждой V внутри U, где верно p, верно q | правило, которое держится во всех вложенных плоскостях |
| ¬p | ни на какой непустой V внутри U p не верно | «нигде ниже». Это **третье** отрицание: в ядре ¬ — явное (как в DL), «нет вывода» — `unknown`, а «нигде ниже» не выразить |
| ∃x p | U покрыта частями, на каждой есть свой свидетель | свидетели могут **различаться** по частям |
| ∀x p | для каждой V внутри U и каждого x над V | — |

Два свойства: **монотонность** — верное на U верно на любой V внутри U;
**локальность** — верное на каждой части покрытия верно на U. [сверено]

В ядре есть монотонность для фактов и правил (видимость), но **не для выводов**:
специфичность отменяет вывод в узкой плоскости. Это не ошибка, а другая
теория — наследование с исключениями (Horty, Thomason, Touretzky 1990).
Локальности нет: нет покрытий.

## 3. Пучок: данные над областями

[сверено: nLab, sheaf; Abramsky, Brandenburger 2011]

| Операция | Определение | В agl |
| --- | --- | --- |
| **предпучок** | каждой области — данные, каждому вложению V ⊆ U — ограничение | факты и правила, видимые в плоскости |
| **ограничение** | данные над U → данные над V ⊆ U | видимость по вложению — **есть** |
| **покрытие** | семейство частей, объединение которых — U | **нет** для плоскостей (`cover` — только для понятий) |
| **согласованное семейство** | данные на частях, совпадающие на попарных пересечениях | поиск противоречий проверяет ровно согласованность — **есть** |
| **склейка** (существование) | согласованное семейство происходит из данных над U | **нет**: из «верно во всех детях» не следует «верно в родителе» |
| **единственность** | склеенные данные единственны; без существования — «отделимый» предпучок | — |
| **нерв Чеха** | покрытие со всеми конечными пересечениями | замыкание пересечений при поиске (исправление В1) — **есть** |
| **глобальное сечение** | данные над всем пространством, согласные со всеми частями | что верно в корне — **частично** |
| **слой (stalk)** | данные «в точке»: предел по сужающимся окрестностям; элементы — ростки | самая узкая плоскость (листья осей) — понятие есть, операции нет |
| **прямой и обратный образ** f\_\*, f\* | перенос данных вдоль отображения пространств | **нет**: перевод между двумя системами плоскостей (две онтологии, две дисциплины) — это слой эквивалентности H3 |
| **пучкование** | превращение предпучка в пучок [по памяти: дописывает склеенные данные] | **нет** |
| **H¹ Чеха** | данные склейки на пересечениях с условием на тройных [сверено частично: nLab классифицирует так главные расслоения] | **нет**; смысл для agl — не проверен |

## 4. Контекстуальность

[сверено: Abramsky, Brandenburger 2011]

- **Покрытие измерений** — семейство контекстов (совместимых наборов
  измерений), без вложенных друг в друга.
- **Эмпирическая модель** — согласованное семейство: на каждом контексте свои
  данные, совпадающие на пересечениях.
- **Контекстуальность** — у такого семейства **нет глобального сечения**.
  Сильная — нет ни одной глобальной картины, совместимой даже с возможными
  исходами каждого контекста.

Модель Белла согласована на всех пересечениях и ни в одном контексте не
противоречива, но целиком не склеивается. Это не ошибка данных, а свойство
мира, которое теория **обнаруживает** как отдельную категорию.

Для agl: решение 15 совпадает с первой половиной — локально согласованное не
считается противоречием. Второй половины нет: ядро не сообщает, что
согласованные плоскости не склеиваются в одну картину. Это кандидат в
отдельный вид находки — не `conflict`, а «контекстуальность».

## 5. Мера согласованности (Робинсон)

[сверено по аннотации: Robinson, arXiv:1805.08927]

- **Назначение** — данные над каждой областью, выбранные без оглядки на их
  согласие (показания разных датчиков).
- **Радиус согласованности** — насколько сильно расходятся данные на
  пересечениях (верхняя грань расстояний). У глобального сечения он равен 0.
- **Слияние** — найти ближайшее согласованное сечение; исходный радиус
  ограничивает снизу, насколько придётся исказить данные.

Для agl: это кандидат в механизм **сходимости** из H49 (жирафы). Нужна
метрика между выводами — для символьных утверждений её пока нет.
