# Гипотезы

Предложения помощника. **Не приняты**, пока автор прямо не скажет; молчание
автора — не согласие. Принятая гипотеза переносится в
[решения](decisions.md) безлично (решение 30).

Нумерация продолжается с H77. Прежние H0–H76 — в
[archive/hypotheses](archive/hypotheses.md), справочно.

Запись гипотезы: номер, формулировка, пометка «не принято», с какими
принципами и решениями сверена.

## H77. Третий мир для вставки вглубь

**Не принято.** Ни родство, ни устойчивость не требуют по смыслу вставки
нового положения между соседями (решение 26, «вглубь»); в спецификации
фундамента это дыра Д1. Предложение: к Ф3 добавить небольшой мир с
отношением строгого порядка без постоянного сдвига (например, «раньше» на
нескольких событиях без чисел) и вывод оси порядка: носители получают
положения, совместимые с порядком, а новый носитель, известный как
лежащий между двумя, получает середину их положений — без перенумерации.
Вывод оси порядка тогда — третий вид вывода оси рядом с осями значения и
сдвига (`docs/spec/foundation.md` §4).

Сверено: решение 26 (вглубь без перенумерации), принцип 3 (порядок
выводится, а не даётся), принцип 6 (мир — без отбора событий под ответ:
порядок должен быть данными мира, а не подобран под вставку), принцип 4
(не цель по памяти).

## H78. Отбор среди найденных законов по размеру записи

**Не принято.** В мире устойчивости машина находит 113 разных разбиений
плоскостей законами и не выделяет ни одно (`docs/spec/foundation.md`
§13.4, дыры Д2, Д9; раздел «Главное нерешённое»). Предложение: упорядочивать разбиения по наименьшей длине
записи закона, который их задаёт (длина двух слов вместе); первые —
кандидаты на закрепление.
Мерило — структура уже найденного, а не известное понятие. Проверить до
применения: выделяет ли такой порядок разбиение `U N T ⊆ N` или
одинаково ранжирует многие (по сверке вне ядра: этому разбиению
принадлежат 264 закона, в том числе `N T ⊆ T N` длины 4).

Сверено: принцип 4 (порядок не задаётся знанием ответа), принцип 8
(отбор по сложившейся структуре вместо перебора), решение 28 (длина записи
— ресурс машины, не число мира; вопрос остаётся открытым).
