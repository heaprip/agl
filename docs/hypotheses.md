## H77. Третий мир для вставки вглубь

**Не принято.** Ни родство, ни устойчивость не требуют по смыслу вставки
нового положения между соседями (решение 26, «вглубь»); в спецификации
фундамента это дыра Д1. Предложение: к Ф3 добавить небольшой мир с
отношением строгого порядка без постоянного сдвига (например, «раньше» на
нескольких событиях без чисел) и вывод оси порядка: носители получают
положения, совместимые с порядком, а новый носитель, известный как
лежащий между двумя, получает середину их положений — без перенумерации.
Вывод оси порядка тогда — третий вид вывода оси рядом с осями значения и
сдвига (`docs/spec/foundation.md` §4).

Сверено: решение 26 (вглубь без перенумерации), принцип 3 (порядок
выводится, а не даётся), принцип 6 (мир — без отбора событий под ответ:
порядок должен быть данными мира, а не подобран под вставку), принцип 4
(не цель по памяти).

## H78. Отбор среди найденных законов по размеру записи

**Не принято.** В мире устойчивости машина находит 113 разных разбиений
плоскостей законами и не выделяет ни одно (`docs/spec/foundation.md`
прежняя редакция §13.4). Предложение: упорядочивать разбиения по наименьшей длине
записи закона, который их задаёт (длина двух слов вместе); первые —
кандидаты на закрепление.
Мерило — структура уже найденного, а не известное понятие. Проверить до
применения: выделяет ли такой порядок разбиение `U N T ⊆ N` или
одинаково ранжирует многие (по сверке вне ядра: этому разбиению
принадлежат 264 закона, в том числе `N T ⊆ T N` длины 4).

После решения 31 механизм выделения задан заметностью
(`docs/spec/foundation.md` §8.2); эта гипотеза остаётся только как
возможный дополнительный отбор внутри закреплённого (вопрос 1
спецификации).

Сверено: принцип 4 (порядок не задаётся знанием ответа), принцип 8
(отбор по сложившейся структуре вместо перебора), решение 28 (длина записи
— ресурс машины, не число мира; вопрос остаётся открытым).

## H80. Форма компонент координат и пара «объём / содержание»

**Не принято.** Форма разреженной точной записи сверяется с геометрией
понятий в языковых моделях (числа оттуда не берутся, иерархия там — слабый
след):

- вид = род + ортогональное приращение → новая ось или положение глубже;
- несколько родов = сумма направлений → несколько осей у одной точки
  (мать: поколение +1 и пол ж);
- взаимоисключающие значения (симплекс) → ось без порядка;
- понятий больше, чем измерений, за счёт разреженности → разреженная
  запись;
- расщепление признака → вставка промежуточного уровня без перенумерации.

Понятие — пара **объём** (где верно: на каких мирах, проекциях) и
**содержание** (набор законов, признаков); оба — точные битовые векторы.

Сверено: решение 26 (вширь, вглубь, без перенумерации), решение 28
(положения — представление машины), принцип 1 (вектор — точная запись, не
эмбеддинг), принцип 4 (геометрия LLM — звезда для сверки формы, не
источник операций и не вход), решение 11 (LLM — материал, не воспитатель).

## H81. Гипервекторные операции в точной форме

**Не принято.** Операции ядра над точками сверяются с алгеброй
гипервекторов (связывание, наложение, перестановка, сходство) — как со
звездой, без её приближённости:

- связывание роль ⊗ значение — порт; обратимо точно;
- наложение — точная запись по ключам, не «большинство битов»;
- перестановка ρ — сдвиг на оси со сдвигом (ρᵃ·ρᵇ = ρᵃ⁺ᵇ);
- на осях законов — битовые векторы с замыканием по «следует из»: OR,
  AND, «A без B пусто»; на оси без порядка — ключ без порядка;
- сходство — расстояние по роду оси (шаги; число отличающихся законов
  после замыкания).

Ловушка: у машинных операций свои законы (наложение коммутативно и
ассоциативно, склейка ассоциативна по построению). Это законы машины, а не
мира; ядро не засчитывает их как находки.

Сверено: принцип 1, принцип 4 (алгебра гипервекторов — сверка, не
источник операций), решения 26, 33 (точность по роду оси).

## H82. Притирка в координатах

**Не принято.** Притирка двух проекций — поиск точного преобразования,
переводящего одну проекцию в другую; понятие — то, что от него не
меняется (фактор → метаузел → новая ось). Нет преобразования — проекции о
разных понятиях. На мире с разрушенной структурой преобразования не
найдётся — это и есть контроль отбора, которого нет в текущей
спецификации (`docs/spec/foundation.md` §8.2, итог четвёртой проверки).

Сверено: решения 31, 32 (куски — проекции), решение 26 (закреплённое —
новая ось), принцип 6 (мир не подобран под механизм), решение 32.

## H83. Законы как точки

**Не принято.** Сверено с «Алгеброй» Бурбаки, гл. I (звезда, только
сверка):

- коммутативность — симметрия портов отношения действия (поменяли два
  входных порта — отношение то же); сначала локальна (переставимые пары);
- ассоциативность — совпадение двух путей склейки;
- закон как точка — разбиение всех записей выражения на классы
  неразличимых; вложение законов — «следует из»;
- законы вместе дают больше суммы: коммутативность и ассоциативность
  вместе разрешают любую перестановку, по отдельности — нет;
- промежуточное между «закон есть» и «нет» — не точка между ними, а где
  закон верен (плоскость) или новая независимая аксиома (вширь);
- переживёт ли закон построение (часть, фактор, произведение), решает его
  форма: равенство записей переживает всё, «существует» не переживает
  часть, «если…то» не переживает фактор. Это теорема о построениях, не
  критерий заметности (ошибка прежнего захода Ф1).

Сверено: решения 26, 31 (оси — законы), 33 (операции на осях законов),
принцип 3 (свойства выводятся), принцип 4.

## H84. Двигатель роста по Бурбаки: принципы как алгоритмы

Девять принципов перехода признаны верными **как описание** и подход —
принципы как алгоритмы ядра — принят (решение 34). **Не принято:** как
каждый принцип становится алгоритмом ядра, и позиции помощника сверх
описания:

- построения и что они рождают: произведение → новые оси; часть,
  порождённое → плоскость; фактор → ось без порядка (метаузел);
  симметризация, дроби → продолжение оси без перенумерации;
- цикл — повод к оси нового вида или фактору, а не только сообщение об
  аномалии (вопрос автору);
- заметен закон, через который мир расширяется (вопрос автору);
- несколько проекций без ручного отбора — построения ядра над одним
  неотобранным носителем: подмножества с объединением, отношения со
  склейкой, отображения с композицией — три проекции разной природы с
  одной формой «a, b → c» (вопрос автору).

Сверено: принципы 4, 6, 7; решения 26, 32, 34; план Ф4 (маршрут Бурбаки).

## H85. Стартовые примитивы

**Не принято, требует проверки.** Вхождение; положение и ось с точными
операциями своего рода; закон → ось (закрепление); склейка (в координатах —
пересечение признаков, сумма сдвигов, добавление признака); скрытие порта
(сдвиг через скрытое сохраняется как сумма); обращение (знак, `−1`; не
отрицание); метаузел (часть → плоскость, класс → ось); плоскость;
основание с источником. Тождество разведено на три: ноль суммы,
отождествление в плоскости (фактор), равенство записей. Отрицание — язык
(маркер противоречия), не строитель. Транзитивное замыкание — не примитив:
порождается как наименьшее устойчивое.

Соответствие с именами плана Ф1: `Primitive` — вхождение и приём пакета;
`Glue` — склейка; `Hide` — скрытие порта; `Reify` — метаузел (группа как
одна сущность); `Restrict` — плоскость (часть → плоскость); `Derive` —
закон → ось; `Metaedge` — не операция, вхождение с портом на вхождение.
Это пересмотр позиции `docs/spec/foundation.md` §11.1 (одна склейка,
`Reify` не нужен): скрытие, обращение, метаузел и закон → ось получают
собственный смысл в координатах.

Расходится с `docs/plan.md` (Ф1, п. 2): «конъюнкция признаков и
композиция отношений — разные операции», а здесь обе — формы склейки;
`Reify` и `Restrict` пересекаются в «часть → плоскость». Открыто.

Сверено: решения 10, 17 (состав метаядра; 17.2 — отрицание), 26, 31;
принцип 5 (язык ядра — отношения, склейка, плоскости); решение 35.
