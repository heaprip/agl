# Атлас слоёв: проект до кода (H74)

Слово автора (2026-10-25, CLAUDE.local.md): «с нуля» — описать все слои от
первой точки после «ничего»; атлас целиком наш, известные понятия — только
путеводные звёзды для сверки; сущность засчитана, когда ядро прошло путь от
«ничего» до чего-то с похожими свойствами. Уроки слепой рецензии
([blind](../review/2026-10-25-blind.md)): готовые **инструменты** брать
можно (замыкание, гомоморфизм, поиск моделей), готовое **содержание** — нет;
критерии должны уметь провалиться; константы — явные и по сетке.

## 1. Слова

- **Ось** — один закон из перечисленного языка, законы не выбираются:
  (а) равенства двух термов до глубины 2 над x, y, z для всех значений
  (x·y = y·x, (x·y)·z = x·(y·z) …); (б) одно равенство термов глубины ≤ 1
  под любой приставкой кванторов «для всех / существует» над его
  переменными в любом порядке (∀a ∀b ∃x: a·x = b; ∃e ∀x: e·x = x …).
- **Сущность** — конечная модель: множество из n элементов и таблица
  действия. С точностью до переименования элементов (изоморфизм).
- **Микротеория** — набор законов, верных вместе; замкнутая — если нет
  закона, который верен на всех её сущностях и не входит в неё (соответствие
  Галуа, как в `extent.rs`). Плоскость agl: «где верно».
- **Путь** — для каждой сущности и микротеории: из чего и каким шагом
  получена.

## 2. Путь первого куска

1. **Ничего → элементы.** Слой n элементов без строения.
2. **Действие.** Все таблицы на n = 1, 2, 3 (1, 16, 19 683), классы
   изоморфизма; законы каждой таблицы.
3. **Микротеории малых n.** Замкнутые наборы законов на этих таблицах.
4. **Снятие закона** (как абляция H57): для микротеории M и закона L из её
   содержания искать модель M без L на размерах до `N` поиском моделей
   (перебор таблицы с проверкой законов на частичном заполнении и отсечением
   изоморфных — приём Mace4). Нашлась — L случаен для малых n; нет до `N`
   — L «следует до N» (свидетельство, не доказательство).
5. Звёзды отмечаются только в приёмке: полугруппа, моноид, группа,
   переместительность; дальше — Q8 (слой подструктур, следующий кусок) и
   тело кватернионов (недостижимо конечным путём — Веддербёрн).

Константы первого куска: `DEPTH = 2`, переменных 3, `N = 6`. Их
действие печатается; сетка `DEPTH` 1–2, `N` 4–7 — в отчёте.

## 3. Критерии (до прогона; каждый может провалиться)

Звёзды — числа из литературы [по памяти; сверить в приёмке, не в ядре]:
магм с точностью до изоморфизма 1, 10, 3330 для n = 1, 2, 3; групп порядка
1–6 — 1, 1, 1, 2, 1, 2.

1. **Классы изоморфизма магм** на n = 1, 2, 3 — ровно 1, 10, 3330.
2. **Группы как микротеория.** Найдётся замкнутая микротеория малых n,
   чьи сущности на n ≤ 3 — ровно группы (по одной на каждый n). Её
   кратчайшее определение D (наименьший набор законов, выделяющий её среди
   всех таблиц n ≤ 3) ядро находит само. Поиск моделей D на n = 1…6 даёт
   1, 1, 1, 2, 1, 2 класса. Провал возможен: D может выделять группы на
   n ≤ 3 и не выделять дальше.
3. **Случайное у малых.** Переместительность — в содержании, но не
   следует из D: снятие находит модель D без неё ровно на n = 6, одну с
   точностью до изоморфизма; на n = 1…5 — ни одной.
4. **Контроль, который может провалиться.** Снятие сочетательности из
   «группы» на n ≤ 6 должно найти модели (квазигруппы с единицей — лупы,
   неассоциативные с n = 5) [по памяти]; снятие закона, который из
   остальных следует (например, единственность единицы, если он попадёт в
   словарь), моделей найти не должно ни на каком n.
5. **Детерминизм** — побайтно при перестановке; от порядка таблиц не
   зависит.
6. **Нет звёзд в ядре.** В коде атласа нет слов «group», «monoid»,
   «commutative» и т. п.; проверка — по всем файлам `src/`, не по одному.

## 4. Итоги первого куска (2026-10-25)

Код — `src/atlas.rs`, приёмка — `tests/atlas.rs` (звёзды только там).
Язык — 1969 законов; атлас n ≤ 3 строится за 0,4 с.

| Критерий | Итог |
|---|---|
| 1. Магмы 1, 10, 3330 | выполнен |
| 2. Группы как микротеория | **в исходной форме провален**, см. ниже |
| 3. Переместительность случайна | выполнен на ветви звезды: снятие даёт одну таблицу, на n = 6, ниже — ни одной; это S3 по звезде |
| 4. Свободный закон против следствия | выполнен: без сочетательности таблицы есть уже на n ≤ 4; без единицы (`∃x∀y: y = x·y`, следует из трёх) — ни одной до n = 6 |
| 5. Детерминизм | поиск не зависит от порядка законов (n ≤ 5); перебор без случайности |
| 6. Нет звёзд в ядре | выполнен по всему `src/`: алгебраические имена; «group» — в атласе (в других файлах это обычное слово) |

**Почему провален критерий 2.** Набор групп n ≤ 3 замкнут: 156 законов
содержания. Кратчайшее определение среди таблиц n ≤ 3 — два закона:
`∀x∀y: x·(y·x) = (x·x)·y` и `∀x∀y∃z: x = y·z`. Таких определений из двух
законов — 10. На n = 4, 5 они дают 2 и 2 (первое) или 2 и 1 (остальные), на
n = 6 первое — одну таблицу. Первый закон в группе равносилен
переместительности, и все десять ведут в переместительную ветвь. Ветвь
звезды — три закона: сочетательность и решимость `x = y·z`, `x = z·y`. Все
три из содержания, на n = 1…6 они дают 1, 1, 1, 2, 1, 2.

Причина не в коде, а в данных: все группы порядка ≤ 5 переместительны, так
что слой n ≤ 3 (и даже n ≤ 5) не отличает «группу» от «переместительной
группы». Уточнение по контрпримеру — добавить в определение нарушенный закон
содержания — тоже не помогает: переместительность в содержании, и S3 будет
отброшена как аномалия. Кратчайшее определение выбирает узкую ветвь, звезда
— широкую. Значит, малый слой даёт не одну микротеорию, а **развилку**:
определения, равные на n ≤ 3, расходятся на n = 5, 6.

**Поиск моделей.** Первая версия (клетки по порядку, проверка законов на
частичной таблице, отсечение одинаковых) на n = 5 — 42 млн узлов, 13 с; n = 6
не дождались. Сейчас у каждой пустой клетки хранится множество ещё возможных
значений; закон читается в трёх значениях по этим множествам, после каждого
хода невозможные значения вычёркиваются, клетка с одним значением его
получает, следующей берётся самая узкая. Итог: n = 5 — 2321 узел, 0,1 с; ветвь
звезды на n = 6 — 742 узла, 0,3 с; кратчайшее определение на n = 6 — 227 тыс.
узлов, 30 с.

**Дальше (предложение).** Показывать развилку как предмет атласа: все
определения малого слоя и как они расходятся на больших n; ветви — с
таблицами-свидетелями. Определений из трёх законов около 2500 по классам
подписи — по ним нужен ещё более быстрый поиск или отбор.
