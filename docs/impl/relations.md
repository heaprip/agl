# Фундамент на отношениях: проект до кода (H75)

Предложение помощника (2026-10-25), не принято. Повод — проверка атласа H74
по понятиям автора: атлас вырос в отдельный алгебраический вычислитель рядом
с agl. Сущность в нём — таблица действия a·b = c (функция, а не отношение);
плоскости ядра не используются; основания («следует до N», «выведено»)
переизобретены строками журнала; закрепление засчитало совпадение семи
определений одной линии проверки (модели до n = 6) за сходимость, и вывод в
§12 этот род разделил; закрепление пишется само, без форка, и не
пересматривается.

Слово автора: фундамент править сразу, глобальных правок не бояться.

## 1. Принцип

Один механизм на каждом слое — механизм чистого мира H72
([clean](clean.md)):

1. мир — конечные отношения как факты, без отбора;
2. банк выражений — склейка тел (единственное действие над выражениями);
3. закон — совпадение или вложение объёмов; логика (гомоморфизм запросов,
   Чандра — Мерлин) отделена от мира;
4. род — понятие анализа формальных понятий над законами;
5. опора — с основой (на чём проверено) и снятием.

Новое — **слои**. Склейка двух выражений с разными дырками R и S на всех
парах отношений мира даёт отношение между отношениями: g(r, s, t) — «склейка
g на r и s имеет объём t». Это следующая ступень шкалы Бурбаки:
𝔓(E×E) → отношения на 𝔓(E×E). Действия не даны: композиция отношений —
одна из склеек; что склейка однозначна (у пары r, s один t), — следствие
логики (объём запроса определён частями), что она всюду определена, — свойство
мира (в нём есть все отношения). Сочетательность композиции — теорема
логики (запросы (R;S);T и R;(S;T) равны по гомоморфизму), а не наблюдение.

Сущности следующего слоя — наборы отношений, замкнутые относительно такой
склейки (порождённые одним-двумя отношениями мира). Их законы находит тот же
банк, но над выведенным отношением g, ограниченным на набор. Набор без
замкнутости — частичное отношение; отношениям это естественно.

## 2. Как это ложится на понятия автора

| Понятие | Где |
|---|---|
| отношения первичны | сущность — отношение; действие — выведенное однозначное отношение |
| плоскость | ось `ground` (логика ⊃ мир n ⊃ …) и ось слоя; закон верен @ плоскость |
| основание | логика и проверка всего замкнутого мира — строгое; обобщение по мирам — отменяемое, контрпример на большем мире — опровергатель |
| противоречие локализовано | обобщение «верно на мирах n ≤ 3» против контрпримера логики (канонической базы запроса) — конфликт на пересечении, его показывает ядро |
| сходимость независимых линий | закрепление требует двух разных родов основания: логика и мир |
| форк, пересмотр | закреплённое — в плоскости-форке; опровергатель снимает его на своей плоскости |
| аномалия → новая ось | закон мира, которого нет в логике, — повод для новой оси (слоя) |
| метаребро | отношение между отношениями — ребро, концы которого — рёбра |
| номер с промежутками | содержание сущности — набор её законов (битовый вектор); вложение — по объёму |

## 3. Ступени

- **А. Отношения между отношениями** (этот раздел — критерии ниже).
- **Б. Сущности слоя 2**: замкнутые наборы, порождённые 1–2 отношениями;
  законы банком над выведенным отношением; роды; закрепление по двум линиям
  в форке; пересмотр.
- **В. Логика сильнее запросов**: инструменты H74 (поиск моделей SAT,
  пополнение правил) как строгое основание там, где гомоморфизма запросов
  мало (законы с «существует», отрицание).
- **Г. Атлас H74** остаётся только сверкой: что из найденного там ядро
  проходит по отношениям.

## 4. Ступень А: критерии (до прогона)

Миры: все бинарные отношения на 2 точках (16) и на 3 точках (512) — без
отбора.

1. **Склейки двух дырок.** Один круг склейки R и S (7 способов отождествить
   концы, все пары голов), каноническая форма и ядро запроса с метками
   дырок. Печатается число различных по логике склеек; среди них
   композиция, пересечение и обращения — не названные в коде.
2. **Однозначность — логика, полнота — мир.** Для каждой склейки выведенное
   отношение g на мирах n = 2, 3 однозначно и всюду определено; в мире
   с не всеми отношениями (контроль: восемь отношений H72) полнота
   нарушается, однозначность — нет.
3. **Сочетательность и переставимость по логике.** Для каждой склейки ядро
   решает по гомоморфизму трёхдырочных запросов, равны ли g(g(R,S),T) и
   g(R,g(S,T)), g(R,S) и g(S,R). Проверка на мирах n = 2, 3 не
   противоречит логике (где логика «да» — мир «да»). Где логика «нет», а мир
   n ≤ 3 «да», — закон мира, локализованный на плоскости n ≤ 3; таких ждём
   немного или ни одного, провал возможен в обе стороны.
4. **В ядре.** Итог выгружается в `.agl`: факты @ плоскости по оси
   `ground` (логика, мир n2, мир n3); обобщение «верно на мирах ⇒ верно» —
   отменяемое правило. Ядро прогоняет файл: конфликтов нет там, где логика и
   мир согласны; закон мира без логики, если найдётся, даёт видимый конфликт
   на пересечении, а не молчание.
5. **Детерминизм; нет имён** («композиция», «ассоциативность») в `src/`.

## 5. Ступень А: итог (2026-10-25)

Код — `src/layer.rs`, `agl --layer МИР...`; приёмка — `tests/layer.rs`.

**Поправка по ходу, до итога.** Первая версия проверяла два закона по
именам (сочетательность, переставимость) — это зашитый перечень, то же, за
что атлас назван калькулятором. Заменено механизмом H72: из склейки
строятся все выражения глубины ≤ 2 над дырками R, S, T (147 — та же F(3, 2),
что в §10 атласа); закон — совпадение выражений на мире 2 точек, логика
решает, теорема ли это, мир 3 точек проверяет остальное. Именованная
проверка дала то же (17 сочетательных по логике, 6 переставимых, мир
согласен), но в код не вошла.

1. Склеек двух дырок, различных по логике, — **60**; среди них композиция
   {x,y | R(x,a), S(a,y)} и пересечение {x,y | R(x,y), S(x,y)} — в коде не
   названы, имена только в тесте.
2. На мирах всех отношений 2 и 3 точек все 60 всюду определены;
   однозначность — по построению (объём запроса определён частями). В мире
   из 64 отношений 3 точек часть склеек определена не всюду.
3. Законов найдено **1283**: 1253 — теоремы логики, 30 — верны на всех
   отношениях 2 точек, логикой не даются, и мир 3 точек каждый опровергает.
   Законов мира сверх логики на 3 точках — ни одного. Пример: для композиции
   R∘R = (R∘R)∘(R∘R) верно на 2 точках и ложно на 3; сочетательность
   R∘(S∘T) = (R∘S)∘T — теорема логики.
4. В ядре: 2596 вопросов, все ответы ожидаемые. Чтобы противоречие не было
   молчаливым, ядро получило раздел отчёта **«исключения»**: вывод, побитый
   на более узкой плоскости, печатается с плоскостью и тем, кто его побил.
   Здесь — 46 исключений по 30 законам («обобщение с n2 побито на n3
   замороженным запросом»). В старых казусах так проявились ровно известные
   исключения: личинки звонцов в газообмене, два в «Праведных».
5. Порядок отношений мира вывода не меняет; имён законов и склеек в `src/`
   нет.
