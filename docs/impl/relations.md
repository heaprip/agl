# Фундамент на отношениях: проект до кода (H75)

Предложение помощника (2026-10-25), не принято. Повод — проверка атласа H74
по понятиям автора: атлас вырос в отдельный алгебраический вычислитель рядом
с agl. Сущность в нём — таблица действия a·b = c (функция, а не отношение);
плоскости ядра не используются; основания («следует до N», «выведено»)
переизобретены строками журнала; закрепление засчитало совпадение семи
определений одной линии проверки (модели до n = 6) за сходимость, и вывод в
§12 этот род разделил; закрепление пишется само, без форка, и не
пересматривается.

Слово автора: фундамент править сразу, глобальных правок не бояться.

## 1. Принцип

Один механизм на каждом слое — механизм чистого мира H72
([clean](clean.md)):

1. мир — конечные отношения как факты, без отбора;
2. банк выражений — склейка тел (единственное действие над выражениями);
3. закон — совпадение или вложение объёмов; логика (гомоморфизм запросов,
   Чандра — Мерлин) отделена от мира;
4. род — понятие анализа формальных понятий над законами;
5. опора — с основой (на чём проверено) и снятием.

Новое — **слои**. Склейка двух выражений с разными дырками R и S на всех
парах отношений мира даёт отношение между отношениями: g(r, s, t) — «склейка
g на r и s имеет объём t». Это следующая ступень шкалы Бурбаки:
𝔓(E×E) → отношения на 𝔓(E×E). Действия не даны: композиция отношений —
одна из склеек; что склейка однозначна (у пары r, s один t), — следствие
логики (объём запроса определён частями), что она всюду определена, — свойство
мира (в нём есть все отношения). Сочетательность композиции — теорема
логики (запросы (R;S);T и R;(S;T) равны по гомоморфизму), а не наблюдение.

Сущности следующего слоя — наборы отношений, замкнутые относительно такой
склейки (порождённые одним-двумя отношениями мира). Их законы находит тот же
банк, но над выведенным отношением g, ограниченным на набор. Набор без
замкнутости — частичное отношение; отношениям это естественно.

## 2. Как это ложится на понятия автора

| Понятие | Где |
|---|---|
| отношения первичны | сущность — отношение; действие — выведенное однозначное отношение |
| плоскость | ось `ground` (логика ⊃ мир n ⊃ …) и ось слоя; закон верен @ плоскость |
| основание | логика и проверка всего замкнутого мира — строгое; обобщение по мирам — отменяемое, контрпример на большем мире — опровергатель |
| противоречие локализовано | обобщение «верно на мирах n ≤ 3» против контрпримера логики (канонической базы запроса) — конфликт на пересечении, его показывает ядро |
| сходимость независимых линий | закрепление требует двух разных родов основания: логика и мир |
| форк, пересмотр | закреплённое — в плоскости-форке; опровергатель снимает его на своей плоскости |
| аномалия → новая ось | закон мира, которого нет в логике, — повод для новой оси (слоя) |
| метаребро | отношение между отношениями — ребро, концы которого — рёбра |
| номер с промежутками | содержание сущности — набор её законов (битовый вектор); вложение — по объёму |

## 4. Ступень А: критерии (до прогона)

Миры: все бинарные отношения на 2 точках (16) и на 3 точках (512) — без
отбора.

1. **Склейки двух дырок.** Один круг склейки R и S (7 способов отождествить
   концы, все пары голов), каноническая форма и ядро запроса с метками
   дырок. Печатается число различных по логике склеек; среди них
   композиция, пересечение и обращения — не названные в коде.
2. **Однозначность — логика, полнота — мир.** Для каждой склейки выведенное
   отношение g на мирах n = 2, 3 однозначно и всюду определено; в мире
   с не всеми отношениями (контроль: восемь отношений H72) полнота
   нарушается, однозначность — нет.
3. **Сочетательность и переставимость по логике.** Для каждой склейки ядро
   решает по гомоморфизму трёхдырочных запросов, равны ли g(g(R,S),T) и
   g(R,g(S,T)), g(R,S) и g(S,R). Проверка на мирах n = 2, 3 не
   противоречит логике (где логика «да» — мир «да»). Где логика «нет», а мир
   n ≤ 3 «да», — закон мира, локализованный на плоскости n ≤ 3; таких ждём
   немного или ни одного, провал возможен в обе стороны.
4. **В ядре.** Итог выгружается в `.agl`: факты @ плоскости по оси
   `ground` (логика, мир n2, мир n3); обобщение «верно на мирах ⇒ верно» —
   отменяемое правило. Ядро прогоняет файл: конфликтов нет там, где логика и
   мир согласны; закон мира без логики, если найдётся, даёт видимый конфликт
   на пересечении, а не молчание.
5. **Детерминизм; нет имён** («композиция», «ассоциативность») в `src/`.

## 5. Ступень А: итог (2026-10-25)

Код — `src/layer.rs`, `agl --layer МИР...`; приёмка — `tests/layer.rs`.

**Поправка по ходу, до итога.** Первая версия проверяла два закона по
именам (сочетательность, переставимость) — это зашитый перечень, то же, за
что атлас назван калькулятором. Заменено механизмом H72: из склейки
строятся все выражения глубины ≤ 2 над дырками R, S, T (147 — та же F(3, 2),
что в §10 атласа); закон — совпадение выражений на мире 2 точек, логика
решает, теорема ли это, мир 3 точек проверяет остальное. Именованная
проверка дала то же (17 сочетательных по логике, 6 переставимых, мир
согласен), но в код не вошла.

1. Склеек двух дырок, различных по логике, — **60**; среди них композиция
   {x,y | R(x,a), S(a,y)} и пересечение {x,y | R(x,y), S(x,y)} — в коде не
   названы, имена только в тесте.
2. На мирах всех отношений 2 и 3 точек все 60 всюду определены;
   однозначность — по построению (объём запроса определён частями). В мире
   из 64 отношений 3 точек часть склеек определена не всюду.
3. Законов найдено **1283**: 1253 — теоремы логики, 30 — верны на всех
   отношениях 2 точек, логикой не даются, и мир 3 точек каждый опровергает.
   Законов мира сверх логики на 3 точках — ни одного. Пример: для композиции
   R∘R = (R∘R)∘(R∘R) верно на 2 точках и ложно на 3; сочетательность
   R∘(S∘T) = (R∘S)∘T — теорема логики.
4. В ядре: 2596 вопросов, все ответы ожидаемые. Чтобы противоречие не было
   молчаливым, ядро получило раздел отчёта **«исключения»**: вывод, побитый
   на более узкой плоскости, печатается с плоскостью и тем, кто его побил.
   Здесь — 46 исключений по 30 законам («обобщение с n2 побито на n3
   замороженным запросом»). В старых казусах так проявились ровно известные
   исключения: личинки звонцов в газообмене, два в «Праведных».
5. Порядок отношений мира вывода не меняет; имён законов и склеек в `src/`
   нет.

## 6. Ступень А2: одна вселенная конечных отношений (до кода)

Повод — замечание автора о λ-исчислении: ощущение, что оттуда что-то
упущено со стороны фундаментального подхода. Упущено: (1) одна
вселенная вместо стопки слоёв — функция и аргумент в одном мире; (2)
абстракция как действие — выражение становится вещью того же мира; (3)
доказательство — терм (Карри — Ховард); (4) отношение можно запускать назад
(miniKanren). Автор согласился попробовать. Эта ступень — пункты 1 и 2.

**Вселенная** (модель-граф Плоткина — Энгелера — Скотта [по вторичному:
McCusker, 2010]). Из одной точки по одному правилу: токен — точка или пара
«конечный набор токенов → токен». Число токенов по размеру: 1, 1, 2, 4, 10,
25, 67, 184, 519, 1489, 4342, 12 812 (замер). Элемент вселенной — набор
токенов; предел — размер токена N (бесконечное держится конечными кусками:
так модели λ обходят запрет Кантора).

**Два исходных отношения** на токенах, из построения, не выбраны:
`E(c, t)` — c входит в набор токена t (принадлежность ∈ Тарского — Живанта
появляется сама); `P(t, b)` — t ведёт в b.

**Действия — формулы над E и P** с конъюнкцией, «существует» и дополнением
(четыре действия Тарского — Живанта и тождество):

- применение X·Y = {b | ∃t: X(t) ∧ P(t, b) ∧ ¬∃c (E(c, t) ∧ ¬Y(c))} —
  склейка и дополнение («набор t целиком внутри Y»);
- абстракция λx.M = {t | ∃b: P(t, b) ∧ b ∈ M при x = набор t} —
  подстановка принадлежности в дырку и склейка: отношение становится
  набором токенов, то есть вещью того же мира.

Ядро вычисляет формулы от цели (принадлежит ли токен), а не перебором
элементов: связанная переменная берётся из атома, который её задаёт.

Критерии (могут провалиться; имена комбинаторов — только в тестах):
1. **Тот же мир.** Применение и абстракция — формулы над E, P (склейка,
   «существует», дополнение); других действий в вычислителе нет.
2. **Комбинаторы.** K = λx.λy.x и S = λx.λy.λz.x z (y z), построенные
   абстракцией, ведут себя как надо: K·A·B и A, S·K·K и λx.x совпадают на
   токенах размера ≤ m при пределе N. Предсказание до прогона: для K
   достаточно N ≥ 2m + 2 (токен ({b}, (∅, b))).
3. **β-редукция.** Для всех замкнутых λ-термов до заданного размера
   (перечислены по построению, не выбраны) (λx.M)N и M[N/x] совпадают на
   токенах ≤ m при достаточном N; печатается наименьший такой N.
   Провал возможен: усечение может не сходиться так, как обещает
   непрерывность.
4. **Ограничитель.** Вычисление с пределом шагов; на пределе — «не решено»,
   не неверный ответ.
5. Детерминизм.

## 7. Ступень А2: исторический итог (2026-10-25)

Ниже зафиксирован результат прежней параллельной реализации A2. По слову
автора распараллеливание удалено: актуальный код однопоточный. После попытки
переноса A3 полный прогон больше не воспроизвёл эту приёмку; его статус — §8,
а числа времени и памяти ниже нельзя использовать как текущий benchmark.

Код — `src/universe.rs`; приёмка — `tests/universe.rs` (~4 с); прогон —
`cargo run --release --example universe -- m top size`.

1. **Тот же мир — да.** Вычислитель знает только E, P, конъюнкцию,
   «существует» и дополнение; применение и абстракция — формулы над ними
   (`L::formula`). Других действий нет.
2. **Комбинаторы — да.** K·A·B совпадает с A на токенах ≤ m при N ≥ 2m + 2;
   при m = 3 предел точный (при N = 7 ещё нет), при m = 4 хватает N = 8 —
   предсказание оказалось достаточным, но не точным. S·K·K совпадает с I.
3. **β-редукция — да, где решено.** Все 204 редекса замкнутых термов
   размера ≤ 9, токены ≤ 3, пределы N = 3…14: 152 совпадают с N = 3, 22 — с
   N = 4, 7 — с N = 7, 3 — с N = 8, 1 — с N = 11, 2 — с N = 14. «Никогда» —
   ни одного. **17 не решено**: упёрлись в предел шагов при больших N; у
   всех внутри самоприменение (λx.x x). Наименьший пример поздней сходимости
   — (λx.x x)(λx.x): только с N = 14, как и предсказано (нужен токен
   размера 14).
4. **Ограничитель — да.** На пределе шагов ответ «не решено», а не неверный
   ответ; память ответов ≤ 2²¹ записей на все потоки вместе.
5. **Детерминизм старой реализации — да.** Ответы не зависели от того, что
   спрашивали раньше; параллельные результаты собирались в исходном порядке.

**Историческое ускорение.** Подформулы хранились один раз в канонической форме (имена
переменных — по порядку появления), так что выученное в одной формуле
служило всем, где она есть; редексы делились по ядрам. Тогда прогон п. 3 дал
146 с → 45 с, пик памяти 300 МБ. Эти цифры отменены как актуальная приёмка.
Основная работа была перебором токенов, ведущих в цель, при вложенных
применениях; это оставляло 17 нерешённых.

Что это значит: в одной вселенной из одной точки и двух отношений, взятых из
построения, функция и аргумент — вещи одного мира, и вычисление λ-термов
сходится конечными кусками. Следующее по плану: запуск отношения назад
(miniKanren) вместо перебора токенов — он же должен снять нерешённые 17.

## 8. Метод вычисления на отношениях (до кода)

Повод — вопрос, на каких рельсах А2: мир в ней из отношений, а язык
вопросов и вычислитель — λ-термы, то есть язык функций, отвергнутый раньше
(origin §7). Слово: λ — только звезда; записать собственный метод, прежде
чем писать код дальше.

Отдельные части метода известны: алгебра отношений (Тарский — Живант),
запросы-склейки и их равенство по гомоморфизму (Чандра — Мерлин), модель-граф
(Плоткин — Энгелер — Скотт), отменяемый вывод, анализ формальных понятий.
Своё — сборка и то, что результат вычисления несёт плоскость и основание.
Соседи для сверки (не сверено): Datalog с контекстами, микротеории Cyc.

**Материал.** Точка и токены, построенные из неё одним правилом; два
отношения из построения: E(c, t) — c входит в набор t; P(t, b) — t ведёт в
b. Других данных нет. Объём — множество токенов (или кортежей); хранится
целиком, множеством за раз, а не по одному.

**Один шаг — склейка.** Выражение — запрос: тела над отношениями с дырками,
склеенные отождествлением концов; «существует» — забыть конец. Дополнение —
только внутри плоскости (конечного предела): «не входит» имеет смысл лишь
там, где известно, что есть. Функции не примитив: однозначность — свойство
некоторых склеек (ступень А, §5 п. 2).

**Абстракция — склейка становится вещью.** Построенная склейка с дыркой
получает собственную идентичность и может занять роль в другом отношении.
Её объём при данном пределе — проекция этой сущности, а не её идентичность:
разные пути построения могут совпасть на одном N и разойтись на другом. Это
отношение об отношении (метаребро), а не функция. «Применение» — одна из
склеек: b, в который ведёт токен из X, чей набор целиком внутри Y; в коде
оно не названо.

**Плоскость.** Предел N (наибольший размер токена) — плоскость; результат —
не значение, а «объём верен @ N на основании». Совпадение двух выражений на
пределах от N₀ — отменяемое обобщение, опровергатель — больший предел, где
они расходятся; ядро показывает его исключением (раздел отчёта, §5 п. 4), а
не цикл в примере, как в §7.

**Основания.** Строгое — логика: равенство запросов по гомоморфизму.
Отменяемое — совпадение на плоскостях. Закрепление — когда сошлись две
независимые линии (логика и мир), в форк, с пересмотром.

**Как считать.** От цели; связанный конец берётся из самого узкого
отношения, которое его задаёт; токены с одним набором — один ключ (при
N = 14 токенов 172 597, различных наборов 35 229, набор ≤ 4 токенов —
замер); выученное хранится по выражению и наборам его свободных концов. Один
поток. Ограничители шагов и памяти; на пределе — «не решено».

**Звёзды** — только в тестах: λ-термы, комбинаторы K, S, β-редукция.
Проверка, что абстракция и склейка ведут себя как функции там, где ждём;
выбирать шаги по ним нельзя.

   N=8 — 3, N=11 — 1, N=14 — 2, не решено — 17); нерешённых не больше 17.
   Провал возможен: вычислитель на λ-термах (замер до переноса) решил на 3
   меньше — 84 с одним потоком против 291 с процессорного времени у `Ask`.
4. Совпадения по пределам выгружаются в `.agl` фактами @ плоскость N;
   ядро само показывает исключения (совпадение на малом N, побитое
   большим). Ручного подсчёта «с какого N» в примере нет.
5. Один поток; пик памяти ≤ 500 МБ; детерминизм.

### Статус A3 после аудита (2026-10-25)

Ступень не прошла эти критерии и остановлена до общего контракта
([architecture](../architecture.md), [аудит](../review/2026-10-25-foundation.md)).
`universe::Find` пока возвращает только множество токенов: у результата нет
идентичности, пути построения, плоскости и основания; `layer::Query` не
расширен; экспорта в `.agl` нет. В восстановленном полном выводе уже первые
30 случаев были `undecided` при допустимых 17 на всём наборе. Старый полный
однопоточный прогон был остановлен после 1749 секунд. Малые тесты проходят,
но не заменяют приёмку на 204 редексах.

Код сохраняется как незавершённый опыт. Следующий шаг — не оптимизация
`Find`, а сквозной тест двух различных конструкций с одной проекцией в одной
плоскости и расхождением в следующей.
