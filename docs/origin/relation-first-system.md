# Relation-first система представления смысла — итоги обсуждения

Ночь 22–23 октября 2026. Отправная точка — «Логика смысла» Делёза.

---

## 1. Идея

Формальная система представления смысла, построенная **снизу вверх** от минимальных сущностей и **отношений между ними**, с прикладными сущностями (правила, оценки, предметные модели) поверх. LLM используется не как ядро, а как источник кандидатов, которых проверяет формальная часть.

Ключевой принцип — **relation-first**: отношения первичны, устойчивые сущности — производные от сети отношений. Отношений будет больше всего, и они гибче всего.

---

## 2. Философские опоры

| Понятие | Откуда | Что даёт системе |
|---|---|---|
| Копии vs симулякры | Делёз, «Логика смысла», нач.; приложение «Платон и симулякр» | Различие внутри самих вещей: подчинённое мере vs чистое становление. Предостережение: любая «эталонная» модель — это платоновский отбор |
| Внешность отношений | Делёз о Юме | Отношения не выводятся из свойств своих членов → relation-first |
| Сингулярности, статический генезис | Серии о сингулярностях | Индивиды и понятия возникают из распределения особых точек |
| Событие (бестелесное, выражается инфинитивом) | Стоики → Делёз | Кандидат на минимальную семантическую сущность |
| Четыре измерения высказывания | Делёз: обозначение, манифестация, сигнификация, смысл | Каркас слоёв: референция, прагматика (говорящий), логика, семантическое ядро |
| Пустая клетка / парадоксальный элемент | Делёз; эссе «По каким критериям узнают структурализм?» | Элемент без фиксированного места, который держит систему подвижной. Систему нельзя полностью замкнуть |
| Неопределяемые примитивы | Гильберт, «Основания геометрии»; Вежбицкая | Простейшие понятия не объясняются, а задаются отношениями (аксиомами) |
| Понятия ветвятся, а не версионируются линейно | История философии | Новая интерпретация — форк, а не апгрейд; привилегированного «ствола» нет |

**Позиция по основаниям:** модели не нужно обосновывать базовые понятия. Они декларируются как примитивы с внешним источником содержания (опыт, обученные веса), а конфликты купируются паранепротиворечивой логикой. Математическая интуиция — такая же неатомизируемая ось.

**Оговорка:** сам выбор, что считать примитивом, тоже версионируется — через него внутрь попадает исторический багаж.

## 3. Архитектура: по аналогии с LLVM

- **Фронтенды** — разбор естественных языков (лексика, грамматика конкретного языка) в общее представление. LLM здесь уместна: её выход проверяется дальше. Приём проверки — обратная генерация IR в текст.
- **IR** — языконезависимое типизированное представление: события, роли, отношения, примитивы, «дыры».
- **Проходы над IR** — анализ: противоречия, мёртвые элементы, циклы, deprecation-предупреждения, пересмотр.
- **Бэкенды** — символьный вывод с объяснением, статистический предсказатель, генерация текста.

Лексические правила — это фронтенд, а не основа IR: иначе IR унаследует перекосы одного языка.

## 4. Минимальная сущность и примитивы

- Кандидат: **событие с ролями участников** (неодэвидсоновская семантика): «Петя открыл дверь ключом» = событие *открывать* + агенс + объект + инструмент.
- Отношения — первоклассные: могут быть участниками других отношений (отношения об отношениях: модальность, убеждения, источник).
- Примитивы — неопределяемые узлы, смысл которых задаётся только связями.

## 5. Структура данных

Не один граф, а слои с разной скоростью изменения:

1. **Типизированный метаграф / гиперграф**
   - гиперрёбра — n-арные отношения;
   - метарёбра — ребро может быть концом другого ребра;
   - типы на узлах и рёбрах.
2. **Многослойность (multiplex)** — одни сущности в разных слоях (лексика, синтаксис, семантика, прагматика) с межслойными связями.
3. **Именованные подграфы** (как named graphs в RDF) — группировка по источнику, версии, области, корпусу. Запрос = выбор набора подграфов.
4. **Битемпоральная неизменяемая история**
   - два времени: когда утверждение было в силе / когда зафиксировано или истолковано;
   - снимки как в git: адресация по хешу, structural sharing, изменения — рёбра DAG;
   - **lockfile** вывода = набор хешей использованных версий.
5. **Реестр реализаций** — обученные веса не в графе. В графе — узел-«дыра» с декларацией, в реестре — `(ось, область, версия) → хеш артефакта`.
6. **Вычисляемый слой** — графы аргументов / путей под конкретный запрос, сохраняются как результат с lockfile.
7. **Индексы** — по путям, интервальное дерево по периодам, векторный индекс по эмбеддингам.

Веса — версионируемые аннотации на рёбрах, а не часть структуры.

## 6. Качественные оси

Оценочные понятия («разумный», «добросовестный», «иные») — не удаляются, а **явно декларируются как оси** с версионируемыми реализациями.

Декларация оси:
- **тип шкалы** — числовая с размытой границей / порядковая / открытый перечень;
- **факторы «за» и «против»** (как в CATO) — для объяснимости;
- **выход** — распределение + уверенность + доля спорных случаев;
- **происхождение** — область, корпус, период, версия;
- **фиксация версии в каждом выводе** (версия нормы + версия реализации оси).

Предостережения:
- в IR понятие остаётся «дырой», обученное определение — подключаемая реализация, а не замена;
- не обучать только на бесспорных случаях: модель выучит очевидное и ошибётся в спорном. Спорные случаи и особые мнения — в корпус с пометкой;
- различать **случайную неопределённость** (ошибка → линтер) и **намеренную оценочность** (дыра по дизайну). Автоматическое различение — задача фронтенда.

Аналогия из LLVM: `undef` / `poison` — намеренно недоопределённая семантика, которую IR честно несёт дальше.

## 7. Логика и формализмы

- **Паранепротиворечивая логика** — противоречие не взрывает вывод, локализуется.
- **Адаптивные логики** (Батенс, Гент) — классическое поведение где можно, паранепротиворечивое там, где возникла «аномалия». Почти буквально «обратная совместимость».
- **Пересмотр убеждений AGM** (Алчуррон, Гёрденфорс, Макинсон, 1985) — как вносить новое и что удалять; «укоренённость» утверждений. Выросла из задачи отмены норм.
- **Опровержимая логика** — правила с приоритетами и исключениями.
- **Теория аргументации** (Дунг 1995, ASPIC+) — вывод как устойчивое множество аргументов в графе атак.
- **Типизированное лямбда-исчисление** (возможно, зависимые типы) — язык композиции и операций. Само по себе function-first, поэтому не для хранения отношений.
- **Теория категорий** — общий клей: функции и отношения (Rel), композиция; лемма Йонеды как математическая форма relation-first.

## 8. Deprecation с обратной связью

- «Нерекомендуемые» формы выразимы, но дают предупреждение, а не ошибку.
- По ним собирается **телеметрия**: рост использования устаревшего = сигнал, что ядро неадекватно → запуск пересмотра (AGM).
- Коррекция идёт в обе стороны: система направляет, использование переписывает систему.
- Цель — гладкая коррекция под актуальное состояние, не новояз.
- Расхождения между версиями осей = карта того, где реально сдвигается смысл.

## 9. Подсистема стоимости путей (косвенные связи)

- Два режима ответа: полный перебор (корректно, непрактично) vs **эвристический поиск** (A\*): оценка оставшейся стоимости, ранний предполагаемый ответ.
- **Иерархический поиск** — сначала по крупным кластерам, потом уточнение.
- **Anytime-алгоритмы** — грубый ответ сразу, уточнение со временем (ленивые вычисления).
- **Полукольца** — один движок, разные алгебры: кратчайший путь (min, +), самый вероятный (max, ×) и т.д. Наборы весов подключаются как полукольца.
- **Распространение активации** — сигнал растекается и затухает; аналог — распределение внимания в OpenCog.
- У ребра минимум две цены: **стоимость и искажение** (пересказ дёшев и с потерями, первоисточник дорог и точен).
- **Горячие пути** — общеусвоенные понятия как кэш по умолчанию; спуск к источникам только при расхождении. Расхождение с горячим путём — повод сравнить ветки, а не ошибка ветки.
- В многомерных распределениях почти вся вероятностная масса — в малой доле пространства: перебирать нужно в основном её.

## 10. Нейросимвольный цикл с LLM

Как устроены LLM (заметки):
- трансформеры: токены → векторы → слои внимания и FFN → распределение по следующему токену; явных правил нет;
- сеть детерминирована как функция; недетерминизм — от сэмплирования (температура) и на практике от порядка операций с плавающей точкой на GPU (батчи);
- обучение стохастично;
- токенизатор — статистический словарь без семантики; понятия живут в активациях. Их извлекают разреженными автоэнкодерами (Anthropic: «Towards Monosemanticity», «Scaling Monosemanticity»).

Почему трансформеры победили: обучение на сыром тексте без ручного ввода знаний, параллелизм на GPU, предсказуемый рост от масштаба, устойчивость к «грязным» данным (см. Саттон, «The Bitter Lesson», 2019). Цена — нет объяснимости, гарантий непротиворечивости и явных версий.

Цикл «предложи — проверь»:
1. LLM генерирует кандидатов (отношения, определения, правила).
2. IR проверяет: типы, непротиворечивость.
3. Принятое сохраняется; противоречия локализуются и становятся новыми запросами.

Прецеденты: AlphaGeometry, AlphaProof (проверка в Lean). Математика первая, потому что проверка там дешёвая и абсолютная, — это выбор стартовой площадки, а не потолок.

## 11. Прикладной пример: право

- LegalRuleML — декларативный формат; исполняется опровержимыми рассуждателями (например, SPINdle).
- Catala — язык для законов (налоговое право Франции): промежуточное исчисление «по умолчанию», компиляция в несколько языков — почти LLVM-схема в узкой области.
- Предсказание по практике: модели по решениям ЕСПЧ (~79%, 2016); риск закрепления предвзятости (COMPAS).
- Рассуждение по прецедентам: HYPO, CATO (Эшли) — факторы «за/против».
- «Открытая текстура» (Харт), генеральные клаузулы (§242 BGB) — намеренная неопределённость; контрпример — Прусское земское уложение 1794 (~19 тыс. параграфов).
- Рекомендации законодательной техники: Handbuch der Rechtsförmlichkeit, Joint Practical Guide (ЕС), Zasady techniki prawodawczej (PL), методические рекомендации Госдумы.
- Делёз ценил юриспруденцию случаев выше абстрактных прав — философская опора для обучения на решениях.
- Структура права: дерево акта (Akoma Ntoso) + семантический граф ссылок + именованные подграфы по юрисдикциям + битемпоральность (закон на момент фактов vs толкование на момент решения).

## 14. Первый шаг (прототип на выходные)

1. Пара десятков примитивов + типы отношений между ними.
2. Маленький метаграф (именованные подграфы, хеши версий).
3. Цикл: LLM предлагает отношения из узкого текста (например, первая серия «Логики смысла») → проверка типов и непротиворечивости → лог конфликтов.
4. Посмотреть, где идеи держатся, а где нет.
