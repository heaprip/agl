# Аналогия на гликолизе: первая проверка H51 — провал

2026-10-24. Прототип вне ядра: `examples/analogy.rs`. Данные — ствол
гликолиза (11 реакций, 21 вещество) и классы ChEBI из нового шага загрузчика
(`tools/trunk.py fetch-classes`, `data/classes.agl`).

```sh
cargo run --release --example analogy           # ~2 с
AGL_SHOW=1 cargo run --release --example analogy  # с лучшими непроверенными
```

## Что проверялось

Можно ли заметить, что между двумя веществами не хватает реакции, потому что
похожая пара в другом месте её имеет. Ожидание: глюкозо-6-фосфат и
фруктозо-6-фосфат связаны изомеразой (альдоза-фосфат ⇄ кетоза-фосфат);
глицеральдегид-3-фосфат и дигидроксиацетонфосфат — такая же пара (у их кислот
в ChEBI те же классы «aldose phosphate» и «ketose phosphate»). Если удалить
триозофосфатизомеразу (RHEA:18585), механизм должен её предложить.

**Критерий объявлен до прогона:** удалённая реакция — в тройке лучших
предложений, прошедших проверку ядром. Удаляются TPI и ещё 5 реакций по seed 1.

## Механизм

1. Классы вещества — все предки по is_a в ChEBI у него самого и у его
   сопряжённой кислоты. Rhea называет заряженные формы, а классы вроде
   «ketose phosphate» висят на нейтральных; кислота опознаётся по InChI без
   слоя протонирования и большему заряду.
2. База — каждая пара «субстрат A, продукт B» оставшихся реакций. Цель — пара
   веществ C, D, ещё не связанных реакцией.
3. Оценка — аналогическая пропорция A : B :: C : D по классам (Miclet, Prade
   2009): класс подходит, если переход A→B приобретает или теряет его так же,
   как C→D. Учитываются классы, где четвёрка не одинакова. Вес класса —
   редкость, ln(N / число веществ с ним).
4. Перенос — кандидатный вывод по Гентнер: реакция базы, где A заменено на C,
   B — на D, остальные участники как были.
5. Ядро проверяет 40 лучших на баланс атомов и заряда (правила
   `cases/trunk/lib.agl`); ранжируются только сбалансированные.

Енолаза и фосфоглицераткиназа не предлагаются вовсе: перенос меняет только
одну пару участников, а у этих реакций нет базы с той же формой
(субстрат → продукт + вода; другой набор кофакторов).

Единственное сбалансированное предложение среди 40 лучших — во всех шести
прогонах одно и то же: **α-D-глюкозо-6-фосфат = D-глюкопиранозо-6-фосфат**,
по базе «2-фосфоглицерат : 3-фосфоглицерат». Это не реакция: в данных уже есть
`is_a` — α-форма частный случай второй. Механизм принял отношение «вид — род»
за недостающую реакцию. При этом он указал на настоящую шероховатость
данных: гексокиназа даёт одну запись ChEBI, изомераза берёт другую, и
связывает их только `is_a`.

## Почему

Посмотрено по 8 лучшим непроверенным предложениям (`AGL_SHOW=1`).

1. **Пропорция хвалит похожесть пар, а не одинаковость перехода.** Класс, по
   которому A = B и C = D (гексоза против триозы), удовлетворяет пропорции.
   Если C и D почти одинаковы — две формы G6P, — почти все классы такие, и
   оценка высока, что бы ни делала база. Лучшие предложения — «лактат +
   G6P = пируват + α-G6P» и т. п.
2. **Признаки вещества — его личность, а не функциональная группа.** У
   G6P→F6P меняется около 50 классов: всё «глюкозное» теряется, всё
   «фруктозное» появляется. У GAP→DHAP — другие 50. Общих — два: «aldose
   phosphate» и «ketose phosphate». Вес редкости делает хуже: самые редкие
   классы — как раз личные.
3. **Кольцо прячет группу.** G6P в ChEBI — пиранозное кольцо, класса
   «aldehyde» у неё нет; у GAP — есть. Функциональная группа, на которой держится
   аналогия химика, в классах представлена лишь частично.

После провала проверен один вариант: считать только классы, которые меняются
в базе или цели (убрать контекст A = B, C = D). Стало хуже: TPI на 2243-м
месте из 8100, оценка 0.03. Причина 2 осталась. Вариант оставлен в коде
выключенным (`CHANGES_ONLY`); новых вариантов не подбиралось — это была бы
подгонка под ответ.

## Что это говорит о H51

Провал не опровергает схему из трёх шагов ([lessons/reasoning](../lessons/reasoning.md)),
он подтверждает два предупреждения источников:

- **Гентнер:** сопоставлять надо отношения, а не признаки. Здесь сравнивались
  мешки классов. Химик видит аналогию в **переходе группы** (C=O на первом
  атоме → на втором), то есть в отношении внутри молекулы. В данных его нет:
  нужна структура (атомы и связи, например из SMILES, который в ChEBI есть) —
  это та же мысль, что в H42, «множители — не мешок, а структура с ролями».
- **Кант:** меры близости теория не даёт. Взятая мера (пропорция по
  классам с весом редкости) оказалась не той.

Проверка ядром сработала как задумано: из 40 лучших отсеяно 39
несбалансированных, ни одно ложное предложение не прошло как факт.

## Что можно сделать дальше (решает автор)

1. Признаки перехода, а не вещества: разность структур A→B (какая группа
   ушла, какая пришла) по SMILES. Нужен разбор SMILES — в ядре без
   зависимостей это заметная работа; в загрузчике — RDKit как инструмент
   `tools/`.
2. Сначала проверить механизм там, где признаки — отношения: родство
   (`--concepts`), где структура уже есть. «Брат матери : мать :: брат отца :
   ?» — ответ известен.
3. Бэкон: искать только по соседству (общий участник или общий род), а не
   среди всех пар — это и сужает перебор (8000 → десятки), и ближе к тому,
   как описан процесс.
