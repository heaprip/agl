# Вопрос Гамильтона: какой закон снять, шаг 4 лестницы H57, 2026-10-24

Критерий объявлен до прогона (H57, «Шаг 4», коммит f88830a). Здесь только
вход и выход; ход пересчитывается по seed.

## Вход

- Казус `cases/discovery/hamilton.agl`: умножение билинейно, задаётся
  таблицей произведений единиц u0…u3; u0 — единица; квадрат каждой мнимой
  единицы −1. Законы: переместительность и сочетательность проверяются на
  единицах (полная проверка по билинейности), закон нормы — на выборке пар.
- Генератор `examples/hamilton.rs`: уровни по экономии (меньше снятых
  законов, затем меньшая размерность); этап А — все 2n × 2n значений
  (uₐu_b, u_buₐ) для каждой пары единиц, 100 пар-проб от seed; этап Б —
  произведения выживших, 150 проб. Останов на первом уровне с выжившими.
- Тест `tests/discovery.rs`: этап Б при n = 4 на восьми таблицах,
  независимость от перестановки.

```sh
cargo run --release --example hamilton -- 1     # ~30 с
```

## Выход

Запись ядра, одинаково при seed 1, 2, 3, 7:

| n | снят | этап А (выжило по парам) | полных таблиц | выжило |
| --- | --- | --- | --- | --- |
| 3 | — | 0 | 0 | 0 |
| 4 | — | 0, 0, 0 | 0 | 0 |
| 3 | переместительность | 0 | 0 | 0 |
| 3 | сочетательность | 0 | 0 | 0 |
| 3 | норма | 0 | 0 | 0 |
| 4 | **переместительность** | 2, 2, 2 | 8 | **2** |
| 4 | сочетательность | 0, 0, 0 | 0 | 0 |
| 4 | норма | 2, 2, 2 | 8 | 0 |

Выжившие:
- u1u2 = u3, u2u3 = u1, u3u1 = u2, и каждая пара антипереместительна
  (u2u1 = −u3, …) — это ij = k, jk = i, ki = j, ji = −k;
- зеркальная: все знаки минус (то же с u3 ↦ −u3).

| Критерий | Итог |
| --- | --- |
| (а) уровни до (4, снят один) пусты | да |
| (б) ровно две таблицы, только при снятой переместительности | да |
| (в) одинаково при seed 1, 2, 3, 7 | да |

## Толкование помощника

- Тройки невозможны в этом пространстве при любом одном снятом законе — в
  согласии с Гурвицем и Ганкелем. Гамильтон 15 лет искал тройки; здесь
  неудача троек видна за доли секунды, но только потому, что пространство
  поиска конечно и задано.
- Закон нормы на парах сам требует антипереместительности: uₐu_b =
  −u_buₐ. Поэтому при сохранённой переместительности не выживает ничего, и
  снять приходится именно её — ядро выбрало тот же закон, что Гамильтон.
- При снятой норме выживают 8 переместительных таблиц на этапе А (uₐu_b =
  u_buₐ = ±u_c), но все падают на сочетательности: с квадратами −1
  переместительная сочетательная алгебра даёт (u1u2)² = +1, а u3² = −1.

| Дано | Найдено ядром |
| --- | --- |
| базис, билинейность, u0 — единица, квадраты −1, значения ±u_k; три закона; порядок уровней по экономии | что тройки невозможны; что нужна четвёртая единица; что снять надо переместительность; таблицу кватернионов (с точностью до зеркала) |

## Чего опыт не показывает

- Пространство поиска и законы даны; порядок «сначала меньше снятых
  законов» выбран помощником.
- Закон нормы проверяется на выборке; здесь ложных выживших не оказалось,
  но это не доказательство.
- Невозможность доказана только в этом конечном пространстве (значения
  ±u_k, квадраты −1), а не в общем виде.
- Шаг 4 не связан с библиотекой шага 3: присоединение корня и снятие
  закона пока два разных приёма. Общего механизма «какой приём применить»
  нет.

## Абляция данного (после возражения автора)

Возражение: результат подогнан под заранее известный ответ. Проверка объявлена до прогона
(H57, коммит 5bed365): убрать по одному то, что задано со знанием ответа.

```sh
cargo run --release --example hamilton -- 1 free-squares zero   # ~150 с
```

**Ошибка по ходу.** Первый прогон со свободными квадратами не нашёл
кватернионов даже при снятой переместительности. Причина — в ядре: при
100 000 атомах замыкание обрывалось молча, и невыведенное читалось как
«нет». Теперь обрыв — ошибка в отчёте, генераторы проверяют его и делят
таблицы на пачки по 32. Все прошлые опыты (шаги 1–4, аналогия) перепроверены
с этой проверкой: обрывов не было, итоги те же.

Запись ядра, seed 1 и 7 одинаково; первый уровень с выжившими во всех
вариантах — (n = 4, снят один закон):

| Вариант | снята переместительность | снята норма | снята сочетательность |
| --- | --- | --- | --- |
| (0) как в шаге 4 | 2: кватернионы и зеркало | 0 | 0 |
| (1) квадраты u2, u3 свободны (−1, 0, +1) | 2: те же, квадраты выбраны −1 | **4** | 0 |
| (2) произведение может быть нулём | 2: те же | 0 | 0 |
| (3) оба | 2: те же | **6** | 0 |

Новые выжившие при снятой норме — переместительные таблицы:
- u2² = −1, u3² = +1, u1u2 = u2u1 = u3, u1u3 = −u2, u2u3 = −u1 (и знаковые
  варианты) — бикомплексные числа: две переместительные мнимые единицы,
  их произведение в квадрате +1 (Cockle 1848, Segre 1892 [по вторичному, distill]);
- с нулём: u2² = u3² = 0, u2u3 = 0, u1u2 = u3 — дуальные над комплексными, ℂ[ε]/(ε²) (не «dual-complex numbers» литературы, см. [distill](../lessons/distill.md)); комплексные числа с
  дуальной единицей ε² = 0.

**Вердикт.** Пока норма действует, свободные квадраты и ноль ничего не
меняют — это выведено на бумаге и подтвердилось. Но **единственность**
ответа шага 4 держалась на данном: с квадратами −1 вторая ветвь была
закрыта заранее. Без этого законы и экономия дают две равноценные ветви
одного уровня: снять переместительность (кватернионы) или снять норму
(бикомплексные). Обе в истории были. Выбор между ними ядро сделать не
может: он зависит от цели — Гамильтону нужен был закон нормы, потому что
он искал алгебру длин и поворотов. Значит, в сите не хватает пункта «что
нужно сохранить ради задачи»; сейчас его подставлял помощник через данное.

## Память

Вопрос автора: почему опыт ест так много памяти. Замыкание в 100 000
атомов — около 510 МБ, порядка 5 КБ на атом: ключи атомов и списки посылок
в записи вывода хранятся строками, у агрегата посылки — все свёрнутые
атомы. Шесть параллельных прогонов без деления на пачки занимали несколько
гигабайт. С пачками по 32 пик одного прогона — 118 МБ, но время выросло до
150 с. Лечение — интернирование (H2, замер добавлен туда).
