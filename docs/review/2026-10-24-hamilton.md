# Вопрос Гамильтона: какой закон снять, шаг 4 лестницы H57, 2026-10-24

Критерий объявлен до прогона (H57, «Шаг 4», коммит f88830a). Здесь только
вход и выход; ход пересчитывается по seed.

## Вход

- Казус `cases/discovery/hamilton.agl`: умножение билинейно, задаётся
  таблицей произведений единиц u0…u3; u0 — единица; квадрат каждой мнимой
  единицы −1. Законы: переместительность и сочетательность проверяются на
  единицах (полная проверка по билинейности), закон нормы — на выборке пар.
- Генератор `examples/hamilton.rs`: уровни по экономии (меньше снятых
  законов, затем меньшая размерность); этап А — все 2n × 2n значений
  (uₐu_b, u_buₐ) для каждой пары единиц, 100 пар-проб от seed; этап Б —
  произведения выживших, 150 проб. Останов на первом уровне с выжившими.
- Тест `tests/discovery.rs`: этап Б при n = 4 на восьми таблицах,
  независимость от перестановки.

```sh
cargo run --release --example hamilton -- 1     # ~30 с
```

## Выход

Запись ядра, одинаково при seed 1, 2, 3, 7:

| n | снят | этап А (выжило по парам) | полных таблиц | выжило |
| --- | --- | --- | --- | --- |
| 3 | — | 0 | 0 | 0 |
| 4 | — | 0, 0, 0 | 0 | 0 |
| 3 | переместительность | 0 | 0 | 0 |
| 3 | сочетательность | 0 | 0 | 0 |
| 3 | норма | 0 | 0 | 0 |
| 4 | **переместительность** | 2, 2, 2 | 8 | **2** |
| 4 | сочетательность | 0, 0, 0 | 0 | 0 |
| 4 | норма | 2, 2, 2 | 8 | 0 |

Выжившие:
- u1u2 = u3, u2u3 = u1, u3u1 = u2, и каждая пара антипереместительна
  (u2u1 = −u3, …) — это ij = k, jk = i, ki = j, ji = −k;
- зеркальная: все знаки минус (то же с u3 ↦ −u3).

| Критерий | Итог |
| --- | --- |
| (а) уровни до (4, снят один) пусты | да |
| (б) ровно две таблицы, только при снятой переместительности | да |
| (в) одинаково при seed 1, 2, 3, 7 | да |

## Толкование помощника

- Тройки невозможны в этом пространстве при любом одном снятом законе — в
  согласии с Гурвицем и Ганкелем. Гамильтон 15 лет искал тройки; здесь
  неудача троек видна за доли секунды, но только потому, что пространство
  поиска конечно и задано.
- Закон нормы на парах сам требует антипереместительности: uₐu_b =
  −u_buₐ. Поэтому при сохранённой переместительности не выживает ничего, и
  снять приходится именно её — ядро выбрало тот же закон, что Гамильтон.
- При снятой норме выживают 8 переместительных таблиц на этапе А (uₐu_b =
  u_buₐ = ±u_c), но все падают на сочетательности: с квадратами −1
  переместительная сочетательная алгебра даёт (u1u2)² = +1, а u3² = −1.

## Чего опыт не показывает

- Пространство поиска и законы даны; порядок «сначала меньше снятых
  законов» выбран помощником.
- Закон нормы проверяется на выборке; здесь ложных выживших не оказалось,
  но это не доказательство.
- Невозможность доказана только в этом конечном пространстве (значения
  ±u_k, квадраты −1), а не в общем виде.
- Шаг 4 не связан с библиотекой шага 3: присоединение корня и снятие
  закона пока два разных приёма. Общего механизма «какой приём применить»
  нет.
