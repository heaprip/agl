# Плоскости agl глазами пучков: что следует из определений, а что самодельное

Сверка на бумаге, 2026-10-24 (H50). Вопрос: если читать плоскости agl как
области, а утверждения — как данные над областями, какое поведение ядра
следует из определений теории пучков, какое пришло из другой теории, а какое
придумано по случаю и расходится с определениями. Кода не меняет. Цель — та
же, что у эталона DL (`tests/oracle.rs`): проверять ядро по определениям, а
не по интуиции.

## Словарь

Пучок — математика истины, которая верна локально. Нужны пять понятий.

| Пучки | agl |
| --- | --- |
| открытая область | плоскость (набор ограничений по осям) |
| вложение областей | `value v in PARENT`; плоскость внутри плоскости |
| пересечение | пересечение плоскостей, `overlap`, составное `a∩b` |
| **ограничение**: верное на области верно на её части | видимость: факт или правило видны во всех более узких плоскостях |
| **покрытие**: область — объединение частей | нет (см. ниже) |
| **склейка**: части, согласные на пересечениях, дают целое | нет |
| истинное значение в топосе — **область, где утверждение верно** | нет: ядро отвечает «верно ли в плоскости P», а не «где верно» |

Плоскости agl — «прямоугольники»: по каждой оси одно значение, свободная ось —
вся ось. Они замкнуты относительно пересечения и образуют базу топологии.
Утверждения программы (факты и правила) образуют **предпучок**: всё, что видно
в плоскости P, видно и в любой плоскости внутри P.

## Следует из определений

1. **Видимость по вложению** — это ограничение предпучка. Решение 15 и
   казус с газообменом здесь совпадают с теорией дословно.
2. **Поиск противоречий по замыканию пересечений полон** (исправление В1).
   Набор видимых утверждений в контексте `c` зависит только от множества
   используемых плоскостей S(c), которые содержат `c`. Самый широкий контекст
   с тем же набором — пересечение всех плоскостей из S(c), и других входов у
   вывода нет: специфичность тоже смотрит только на плоскости правил. Значит,
   вычисление во всех непустых пересечениях используемых плоскостей
   перебирает все различные наборы входов, и других мест для конфликта нет.
   В теории это **нерв** покрытия (Чех): все конечные пересечения, а не
   только попарные. Попарных не хватало потому, что у вывода бывает больше
   двух посылок из разных плоскостей (`b3`: факт в `x`, правила в `y` и `z`).
   Без предела числа контекстов поиск точен; предел честно сообщается.
3. **Показывать конфликт в самом широком контексте** — это показывать его
   на пересечении S(c), где он впервые возникает. Выбор, сделанный сегодня
   при исправлении В1, — не вкусовой.
4. **Решение 15** («противоречие есть только там, где плоскости
   пересекаются») совпадает с позицией теории **контекстуальности**
   (Abramsky и Brandenburger 2011). Семейство данных, согласованное на каждом
   пересечении, но без единой глобальной склейки, — не противоречие, а
   контекстуальность; так устроена квантовая механика. Ядро и не обязано
   искать «глобальное» противоречие: решение автора здесь опирается на
   строгую теорию.

## Пришло из другой теории

5. **Специфичность** (узкая плоскость бьёт широкую: личинки звонцов) в пучках
   невозможна: ограничение не может отменить данные. Это теория
   **наследования с исключениями** (Touretzky 1986; Horty, Thomason,
   Touretzky 1990): более частное наследование побеждает. Значит, выводы
   ядра — **не предпучок**: вывод, верный в P, может пропасть в плоскости
   внутри P. Так задумано, но отсюда следствие.
6. **Сужение плоскости по выводам (`situate`) не монотонно.** Любая
   процедура, которая сужает плоскость по выводу и считает, что вывод
   уцелеет после сужения, молча предполагает, что выводы — предпучок. По
   пункту 5 это неверно. Ошибка В2 предсказывается отсюда заранее; сегодняшнее
   исправление (проверять `situated` в итоговой плоскости) — ровно та
   проверка, которой требует определение.

## Расходится с определениями

7. **Перекрытие наследуется вниз.** `overlap a x y` ядро читает как «и
   любая часть `x` пересекается с любой частью `y`»: конфликт фактов в
   `x1` (внутри `x`) и в `y` сообщается в `x1∩y`. Как области это неверно:
   `x` и `y` могут пересекаться только по `x2`. Проверено:

   ```text
   value a x
   value a x1 in x
   value a x2 in x
   value a y
   overlap a x y
   fact f1: p(i: k) @ a:x1
   fact f2: ¬p(i: k) @ a:y
   → conflict Hard on p(i: k) in {a:x1∩y}
   ```

   Сказать «`x1` с `y` не пересекается» нотация не даёт. Последствие —
   конфликты в областях, которые, может быть, пусты. В родстве
   (`genetic∩law`) область заведомо не пуста, так что казус не задет.
8. **Из попарных пересечений выводится общее.** Пересечение трёх значений
   строится, если каждые два пересекаются. Для областей это неверно: три
   области могут пересекаться попарно без общей точки. Последствие то же:
   поиск может заглянуть в пустую область.

   Для 7 и 8 вариант по теории: непустота пересечения — данные, а не
   вывод. Объявленное пересечение непусто; выведенное — «возможно пусто», и
   конфликт в нём помечается «если такая область есть». Решает автор: это
   цена либо лишних объявлений, либо лишних тревог.

## Чего нет и что теория предлагает

9. **Склейки снизу вверх нет.** У значений оси не сказано, исчерпывают ли
   дети родителя. Поэтому, если «есть шерсть» верно в каждой из трёх групп
   млекопитающих, в «млекопитающих» ядро этого не знает. В пучках это и есть
   склейка, но ей нужно **покрытие**: объявление «`mammal` = `monotreme` ∪
   `marsupial` ∪ `placental`». Для понятий такое объявление уже есть
   (`cover`); для плоскостей — нет.
10. **Вопроса «где верно p» нет.** Истинное значение в топосе — область.
    Ядро уже вычисляет все нужные контексты при поиске противоречий; собрать
    наибольшие из тех, где `p` выводится, — дёшево. Это буквально первая фраза
    CLAUDE.md: «плоскости определяют, где утверждение верно».
11. **Сходимости нет.** В истории с жирафами (H49) спор решило согласие
    независимых линий данных. В пучках для этого есть мера — **радиус
    согласованности** (Robinson 2017, слияние данных датчиков): насколько
    сильно расходятся данные из разных источников над одной областью. В ядре
    у атома может быть много выводов, но их согласие ничего не весит.
    Кандидат: «независимые» — выводы с непересекающимися опорами из фактов.

## Итог

| Поведение ядра | Оценка |
| --- | --- |
| видимость по вложению | следует из определений |
| поиск по замыканию пересечений (В1) | следует; доказуемо полон |
| конфликт в самом широком контексте | следует |
| решение 15 | совпадает с контекстуальностью |
| специфичность | из теории наследования, не из пучков |
| проверка `situate` (В2) | требуется определениями |
| перекрытие наследуется вниз | расходится |
| общее из попарных пересечений | расходится |
| склейка, «где верно», сходимость | отсутствуют |

Противоречий с определениями — два, оба в алгебре значений оси и оба в
сторону лишних тревог, не пропущенных конфликтов. Сегодняшние исправления В1
и В2 теория подтверждает задним числом. Значит, перестраивать слой плоскостей
не нужно; нужны три решения автора (7–8, 9, 10) и, возможно, одна новая
механика (11).
