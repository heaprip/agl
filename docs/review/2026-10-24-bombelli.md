# Шаг Бомбелли: аномалия → смена плоскости → проверка ядром (H53), 2026-10-24

Первый шаг вехи Джанибекова, по выбору автора — мнимые числа. Критерий
объявлен до прогона (H53, коммит 25404a0). По поправке автора к H55 здесь
только вход и выход; ход поиска пересчитывается по seed.

## Вход

- Казус `cases/discovery/bombelli.agl`: x³ = 15x + 4; правило Кардано;
  плоскость `pairs`, где число — пара с правилом умножения (объявлено в
  данных, решение 23).
- Генератор `examples/bombelli.rs`: целые пары |a|, |b| ≤ 10 (441), порядок
  от seed, по 50 за раз.
- Тест `tests/discovery.rs`: итог при всех парах и независимость от порядка.

```sh
cargo run --release --example bombelli -- 1        # итог
AGL_TRACE=1 cargo run --release --example bombelli  # ход поиска
cargo run --release -- -v cases/discovery/bombelli.agl  # без пар: аномалия
```

## Выход

| Ожидание | Итог |
| --- | --- |
| 1. Без пар формула неприменима; 4 — корень | да: `formula_applies` → unknown (радикал −121), `satisfies(4)` → yes |
| 2. Ровно один целый кубический корень из 2 ± 11i | да: (2, 1) и (2, −1) |
| 3. Сумма — (4, 0), и 4 удовлетворяет уравнению | да: `cardano_correct(x: 4) @ pairs` → yes |
| 4. Не зависит от seed и порядка | да: seed 1, 2, 3, 7 и три перестановки |

Аномалия сама указала плоскость: несбывшееся правило опирается на
`radicand`, правила с `radicand` есть только в `pairs`. Поиск занял от 200
до 441 пары в зависимости от seed.

Цепочка вывода ядра (`-v`) — это и есть вычисление Бомбелли:
(2, 1)² = (3, 4), (2, 1)³ = (2, 11), то есть 2 + √−121; сопряжённое — так
же; сумма (4, 0).

## Чего опыт не показывает

Представление парами дано, а не найдено. Перебор тривиален (441 пара).
Проверена цепочка «аномалия → мобилизация плоскости → поиск → проверка
ядром → возврат к обычным числам». Открытие самого представления — следующий,
трудный уровень.
