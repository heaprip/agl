# agl — для любого агента (Codex и др.)

Перед любой работой:

0. `docs/understanding.md` — сжатое понимание устройства ядра; первым.
1. `docs/now.md` — где мы, текущая фаза, что в работе.
2. `docs/plan.md` — единственный ход работ.
3. `docs/principles.md` — поправки автора, которые агенты уже нарушали;
   сверять с ними каждое предложение.
4. `docs/decisions.md` — решения автора 1–35.
5. `CLAUDE.md` — правила проекта.

Прошлое (`docs/archive/`, метка `legacy-v0`) — только по прямому слову
автора; код прошлого не материал и не эталон.

Новый модуль в `src/` или `examples/` — сначала строка в `docs/modules.md`
(`tests/registry.rs` проверяет). Закончил задачу — обнови `docs/now.md`.
