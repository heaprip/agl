# Artificial General Logic

Relation-first система представления смысла. Отношения первичны, устойчивые
сущности выводятся из сети отношений. LLM только предлагает кандидатов,
формальное ядро их проверяет. Противоречия не запрещены, а видимы и
локализованы — по плоскостям вопроса и по веткам интерпретации.

**Состояние:** проект перезапущен с чистого листа. Крейт пуст до фазы Ф2:
ядро-машина пишется только после спецификации фундамента. Ход работ —
[docs/plan.md](docs/plan.md), текущая точка — [docs/now.md](docs/now.md).

Прошлое — PoC метаядра v0 и его документы — сохранено: код в метке git
`legacy-v0`, документы в [docs/archive/](docs/archive/README.md).
